# 轮腿机器人 MuJoCo 仿真实验报告

## 一、研究背景

1.仿真部分
主要目的是在mujoco中验证 model-base 的控制的可行性，确认状态机的逻辑正确性。目的是在让模型 “动起来” 的基础上，尽可能接近真实环境下的控制

2.实车调参部分
在 mujoco 完成状态机的逻辑验证之后 ，上实车测试重心和控制权重矩阵与输入权重矩阵等参数是否正确。目的是实现轮腿机器人在现实中能够稳定的前进或后退。

## 二、目前已有研究内容

1.Mujoco 仿真

目前已经完成 MuJoCo 模型与控制程序之间的闭环连接。仿真端读取关节位置、关节速度、轮速、机体姿态、机体速度和轮地接触信息，并将这些量转换为控制器使用的状态；控制器计算后输出腿部关节力矩和轮毂力矩，再作用回 MuJoCo 模型。

基础平衡控制采用全状态 LQR 与局部 PID 配合的思路。串联腿轮腿机器人在前后方向上接近一个带可变腿长机构的两轮倒立摆，腿长变化会改变质心高度和动力学参数，因此机体俯仰、轮轴速度和腿部构型需要放在同一个闭环中考虑。

LQR 中同时考虑：
虚拟腿相对车体的前后倾角、
该倾角变化速度、
轮轴前后位置偏差、
轮轴前后速度偏差、
机体俯仰角偏差、
机体俯仰角速度。

LQR 的作用是在轮轴运动、机体姿态和腿部姿态之间做整体折中，使机器人既能响应速度参考，又不破坏倒立摆平衡。PID 主要承担更局部的目标跟踪，例如腿长保持、横滚补偿、偏航补偿和部分姿态修正。

在站立、前进、后退和转向实验中，机器人能够在约 0.20 m 腿长附近维持站立，并在给定低速速度参考时完成前进、后退和停车回稳。前进和后退本质上与站立属于同一个平衡问题：站立对应零速度参考，前进和后退对应正反方向速度参考，控制器需要在速度跟踪和机体不倒之间保持平衡。转向则通过左右轮差动力矩实现，主平衡闭环仍负责前后方向稳定，偏航控制作为外层补偿叠加到左右轮力矩上。调试过程中也检查了视觉车头方向、控制器前进方向和 MuJoCo 世界坐标之间的对应关系，使 W/S 操作和仿真中的视觉前后方向保持一致。

跳跃实验部分已经实现了一个基于状态切换的控制流程，包括压缩准备、快速蹬伸、离地收腿、预落地伸腿、触地缓冲和恢复站立。跳跃不是单一连续控制问题，而是包含离地、腾空、触地和冲击缓冲的混合控制问题，因此需要结合腿长目标、接触判断、姿态反馈和阶段切换条件进行设计。目前仿真中机器人可以完整经过跳跃状态机并回到站立状态，但是对于仿真中的跳跃稳定性还需要更多的尝试；
