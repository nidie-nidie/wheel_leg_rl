# 轮腿车 SAFE 平衡调试流程

更新日期：2026-06-23

## 1. 调试目标

先让车辆在 `CHASSIS_SAFE` 下以目标腿长完成真正的两轮自平衡，再调位置保持、行驶和起立过程。

“Pitch 稳定”的有效判据是：

- 只有左右驱动轮接触地面，前后导轮不接触地面；
- 保护架或吊绳只负责接车，正常平衡时不提供支撑力矩；
- 小扰动后轮子会向车体倾倒方向移动，并能把车体拉回；
- Pitch 不持续发散，轮子与关节输出不长期饱和；
- 初步目标为连续稳定数秒、Pitch 进入约 `+-5 deg` 范围。该范围是首轮调试判据，不是最终精度指标。

导轮着地后 Pitch 曲线不再变化，只能说明车体被机械结构撑住，不算自平衡成功。

目标 pitch 值：0.03820 rad

目前 safe 状态的控制目标：
腿部theta        → 0
腿部theta速度    → 0
车体位置         → x_set （但有X2_OFFSET=-0.09）
车体速度         → v_set
Pitch            → -X4_OFFSET= -0.0382
Pitch角速度      → 0
腿长             → leg_set

目前 标定的 phi0 平衡点
left_phi0_cmd  ≈ 0.82 rad = 47.0 deg
right_phi0_cmd ≈ 2.32 rad = 133.0 deg

## 2. 当前代码状态

- 普通关节前馈扭矩 `torque_set` 已限制为 `+-7 Nm`；跳跃时限制为 `+-20 Nm`。
- 上述限制只限制 MIT 指令的前馈扭矩。SAFE 还发送 `KP=20`、`KD=1`，实际电机总扭矩还可能包含位置环和速度环的贡献。
- 关节反馈扭矩保护阈值为 `25 Nm`。
- 反馈超限或通信错误目前仍切换到 `CHASSIS_SAFE`，而 SAFE 会继续发力。上车前应改为清除 `start_flag` 并进入 `CHASSIS_OFF` 或独立故障状态。
- 机械角度限位暂未启用，调试时必须使用吊绳或保护架。
- `INIT_LEG_LENGTH` 当前是 `0.20 m`，不是计划中的 `0.25 m`。
- `X2_OFFSET` 当前是 `-0.09 m`。在真正的两轮 Pitch 平衡建立前，不用它补偿车辆倒地或导轮着地问题。
- 精简遥测尚未移植到 clean 工程；没有遥测时不连续修改多个参数。

## 3. 总体顺序

### 阶段 A：安全保护  【√】

1. 确认 START 可以可靠关闭底盘并使电机卸力。     （√）
2. 将关节反馈扭矩超限、遥控器失联和关键电机失联统一处理为 `start_flag=0` 加 `CHASSIS_OFF/FAULT`。
3. 如果 DM-J8009P 当前固件支持驱动器最大电流或最大扭矩设置，在上位机中增加驱动器侧限制。  目前8009 的上位机 电流限制 是 0.44（√）
4. 不把 `DM_T_MAX` 当作硬件限幅修改；它是 MIT CAN 扭矩字段的编码量程。
5. 低扭矩、短时间、吊绳保护下开始测试。   （√）

通过条件：任一保护触发后，关节和轮毂都不再继续输出控制扭矩，并且必须由人工明确复位才能重新启动。

### 阶段 B：建立可观测数据  【√】

从 `rm_test-dev` 复用 UART7 遥测框架，控制在 48 列以内。首轮至少记录：

- 时间、模式、`start_flag`、错误位；
- `INS.Pitch`、Pitch 角速度；
- `v_set`、`v_filter`、`x_set`、`x_filter`；
- 左右 `L0`、腿长目标；
- 左右 `phi0`、`phi0_target`、`phi0_tp`；
- 左右 `wheel_T`、轮速；
- 四个关节 `torque_set` 和四个反馈扭矩；
- 轮毂/关节输出是否触发限幅。

通过条件：一次试验只修改一个变量，数据能够对应到明确的模式、输入、输出和饱和状态。

### 阶段 C：架上静态标定  【√】

可以在架子上完成：

1. 用水平仪或已知机械基准把车体摆到设计的几何零姿态。        
2. 记录此时 `INS.Pitch`，标定 IMU Pitch 零点和正方向。    （√）
3. 分别向前、向后倾斜车体，确认 Pitch 和 Pitch 角速度的正负号。      
4. 架空轮子，以很小的固定轮矩逐个测试左右轮，记录命令正号对应的实际旋转方向和编码器速度符号。
5. 确认四个关节角度、`phi0` 和实际腿部运动方向一致。

普通刚性架子不能标定真实的动态平衡位置，也不能调好 Pitch LQR 增益：车架承担了重力矩，架空轮子也没有地面反力。只有允许车体绕轮轴自由俯仰、并且轮子与滚筒或地面存在正确接触反力的专用试验架，才可以进行部分动态验证；最终仍要落地确认。

### 阶段 D：统一 MuJoCo 和实车符号   【】

MuJoCo 用于建立符号约定和提前发现控制器方向错误，不能直接替代实车标定。

1. 在模型中明确世界坐标的“前进”方向和 Pitch 正方向。
2. 分别给左右轮相同的小正扭矩，确认车体沿定义的前进方向运动。
3. 让模型产生小的正、负 Pitch，确认恢复轮矩使轮子向倾倒方向运动。
4. 检查 XML 中左右轮关节 `axis`、执行器 `gear` 和控制器左右镜像符号。
5. 关闭额外的 wheel override，再检查固件原始 LQR 输出方向；开启 override 得到的稳定结果不能证明实车原始LQR符号正确。
6. 将仿真符号表与阶段 C 的实车架空测试逐项对照。


通过条件：对每个量都能写出一条明确关系，例如“正轮矩 -> 正轮速 -> 车体向前”，并且仿真与实车一致。若不一致，应修正模型映射或实车驱动映射，不能靠调增益掩盖。


### 阶段 E：腿长和姿态几何   【√】

1. 先在低目标腿长和保护架下确认左右 `L0` 测量正确、左右一致且无明显跳变。
2. 检查 `phi0_target`、`phi0_tp`、实际 `phi0` 的相关方向。
3. 把目标腿长逐步调整到最终的 `0.25 m`，每一步确认关节没有持续卡在 `+-7 Nm`。
4. 最终平衡参数必须在 `0.25 m` 下验证，因为腿长变化会改变系统动力学和 LQR 系数。

### 阶段 E1：静态平衡点搜索   【】

该阶段用于在恢复完整 LQR 前，先找出更接近实车的默认几何平衡点。它不是最终两轮自平衡控制，也不要求车辆已经能原地站稳；目标是找出在 `leg_set = 0.25 m` 附近，Pitch 偏差较小、轮端不持续加速、关节不长期饱和时的 `phi0_trim / phi0_eq`。

推荐先进入“静态平衡点搜索模式”：


- 关闭 wheel LQR；
- 关闭 LQR `Tp`，或把 LQR `Tp` 降到很小；
- 轮端只保留速度阻尼；
- `phi0_cmd = pi/2 + phi0_trim`；
- 用很慢的 Pitch 积分项自动寻找 `phi0_trim`。


建议的调试逻辑：

```c
pitch_err = pitch_target - pitch;
phi0_trim += SAFE_PHI0_TRIM_KI * pitch_err * dt;
mySaturate(&phi0_trim, -SAFE_PHI0_TRIM_LIMIT, SAFE_PHI0_TRIM_LIMIT);

left_phi0_cmd  = M_PI_2 + phi0_trim;
right_phi0_cmd = M_PI_2 - phi0_trim;
```

`phi0_trim` 积分必须加保护条件，避免在错误状态下越积越偏：

- 只在 `CHASSIS_SAFE` 且 `start_flag=1` 时积分；
- `|v_filter|` 足够小才积分；
- `wheel_T` 没有长期贴限幅才积分；
- 四个关节 `torque_set` 没有长期贴 `+-7 Nm` 才积分；
- Pitch 没有快速发散才积分；
- `phi0_trim` 必须有限幅，积分速度要慢。

每次测试至少记录：

- `pitch`、`pitch_rate`；
- `phi0_trim`；
- `left_phi0_cmd`、`right_phi0_cmd`；
- 实际 `left_phi0`、`right_phi0`；
- `left_L0`、`right_L0`；
- `left_wheel_T`、`right_wheel_T` 和轮速；
- 四个 `torque_set` 和四个电机反馈扭矩；
- `x_filter`、`v_filter`。

通过条件：

- `phi0_trim` 朝一个方向缓慢变化，并逐渐趋于稳定；
- Pitch 偏差有变小趋势；
- `L0` 仍在 `0.25 m` 附近；
- 关节不长期打满；
- wheel 不持续加速；
- 导轮或保护架没有承担主要支撑力矩。

如果 `phi0_trim` 一直撞到限幅而 Pitch 没有改善，说明没有找到真实静态平衡点，应停止积分并检查轮端阻尼、腿长、重心、Pitch 零点和支撑条件。

若 `phi0_trim` 收敛到某个可复现的值，例如 `-0.12 rad`，则把它固化为默认几何平衡点：

```c
#define SAFE_PHI0_EQ_TRIM (-0.12f)
```

随后再进入阶段 F，恢复完整 LQR：

- 小比例 `SAFE_LQR_WHEEL_SCALE`；
- 小比例 `SAFE_LQR_XV_SCALE`；
- 小比例 `SAFE_LQR_TP_SCALE`；
- 如果完整 LQR 仍然持续推车，则回到模型参数和状态定义检查：重心、惯量、`theta` 定义、`x/v` 定义和轮端符号。


### 阶段 F：真正的两轮 Pitch 平衡   【】

初始条件：`v_set=0`、`x_set=x_filter`，并暂时令 `X2_OFFSET=0`，避免位置环固定偏置干扰方向判断。

1. 保护架留出空行程，使车辆正常状态下不被支撑，同时避免完全摔倒。
2. 前后导轮必须与地面保留可观察间隙。
3. 人工给予很小的前后扰动，先看轮子是否向倾倒方向追车体。
4. 方向错误时先修正 Pitch、轮矩或轮速符号，不调增益。
5. 方向正确后再小步调整 SAFE 的 LQR Pitch 和 Pitch 角速度作用。
6. 轮毂长期卡在 `+-2.41 Nm` 或关节长期卡在 `+-7 Nm` 时属于饱和，停止增加增益并检查模型、重心、腿长和输出分配。

通过条件：导轮不着地，车辆能承受小扰动并稳定数秒，Pitch 不持续发散，输出不持续饱和。

### 阶段 G：把平衡点调到零度附近   【】

- 若车辆能两轮平衡，但 `INS.Pitch` 与机械零度差很多：先修正 IMU 安装和零点标定。
- 若 IMU 零点正确，但系统稳定在小的固定偏角：再检查重心偏置，并小步调整 Pitch 目标或 `X4_OFFSET`。
- 如果偏角很大、导轮着地或输出饱和，该状态不属于可调零点误差，返回阶段 C 至 F。

只有动态平衡方向正确后，才追求更小的稳态Pitch误差。

### 阶段 H：位置保持和 `X2_OFFSET`

1. 车辆先能在零速度指令下完成真正的两轮平衡。
2. 暂时保持 `X2_OFFSET=0`，观察松开摇杆后车辆是否持续向固定方向跑。
3. 区分固定漂移、速度估计偏置、Pitch零点偏置和重心偏置。
4. 确认其余误差后，再以小步长调整 `X2_OFFSET`，目标是减少静止位置漂移，而不是纠正车辆倒地。
5. 每次记录稳态 Pitch、移动方向、移动距离、轮矩和是否饱和。

### 阶段 I：前进、后退和起立

1. 先用小速度命令验证摇杆前推对应物理前进、后推对应物理后退。
2. 检查前后运动时 `v_set`、`v_filter`、轮速和位移符号一致。
3. SAFE 站立和低速行驶稳定后，再测试 `START -> SAFE`、`L1 -> STAND_UP`。
4. 起立PID `KP_CHASSIS_STAND_UP/KD_CHASSIS_STAND_UP` 只在起立阶段调整，不用于解决 SAFE 平衡问题。

## 5. 停止条件

出现以下任一情况立即停止当前试验并进入 OFF：

- 导轮猛烈撞地或保护架持续承重；
- 反馈扭矩超阈值；
- 电机异常升温、异响或通信丢失；
- 轮毂或关节持续饱和；
- Pitch 快速发散且轮子恢复方向错误；
- 遥测丢失，无法判断当前模式和输出。





left_phi0 = 60 deg，right_phi0 = 120 deg：车体 前倾。
left_phi0 = 68 deg，right_phi0 = 112 deg：车体 后倾。








腿长 PID 通过 F0 想撑住 L0



LQR 通过 Tp 想调 pitch



MIT 位置环通过 position_set 想固定腿型



控制逻辑：

1. 编码器角度 -> VMC_calc_1 -> 算出实际 L0、phi0、theta 

2. leg_set(目标腿长 0.25) 和实际 L0 进腿长 PID

3. 腿长 PID 输出虚拟支撑力 F0

4. LQR 输出 Tp    

5. VMC_calc_2 用 F0 和 Tp 算两个关节的 torque_set

6. 同时，phi0_cmd + leg_set 逆解成两个关节 position_set

7. DM 电机收到：
   position_set, vel=0, Kp, Kd, torque_ff
