# 机器人仿真与运动控制技术面试 PPT v2

- `robot_motion_interview_v2.js`：PptxGenJS 可编辑源文件。
- `prepare_assets.py`：从报告 PDF 与 MuJoCo 渲染图准备展示素材。
- `assets/`：SolidWorks 截图、控制路线、MuJoCo 静态渲染和新 VMC 验证数据。
- `deck_v2_validated.pptx`：经 Microsoft PowerPoint 打开、另存、重开与导出验证的版本。
- `powerpoint_export/`：PowerPoint 本体导出的逐页 PNG。

运行源文件时需使用同级任务目录中的 Node 依赖。第 4 页数据只用于离线运动学与雅可比验证，不代表闭环控制或实车验证。
