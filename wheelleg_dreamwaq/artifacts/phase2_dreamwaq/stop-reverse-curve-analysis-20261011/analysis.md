## 判断和建议

这批训练在 1000 iteration 处仍有学习进展，尤其是 run-03。结合它已经通过直线停车/换向专项验收，建议先保持原 profile、物理、随机化和地形，续训这一组另外 1000 iteration，到总计 2000；不急于改奖励或再从零开四组。

后续若执行，建议在总计 1500 和 2000 时对比固定八场景和停车/换向专项，保留 1000 轮 checkpoint 作对照，每半小时监控。评价重点仍是低高度停车、Isaac 后退、MuJoCo 左右换向稳定性。曲线变好而专项表现不变时，再依据具体场景决定调整练习或奖励。

本次只检查和提出建议，没有开始续训。

## 解释边界与证据

训练日志的 Tracking/* 对随机化环境、正负命令、各高度和练习阶段做聚合，并含训练探索。它不能单独给出后退、低高度停车或换向阶段的改善量，也不能直接与固定确定性评估 MAE 等同。当前字段没有按这些目标场景分组；高度 offset 标签按 reset 高度偏移分组，不是按目标站立高度分组。
