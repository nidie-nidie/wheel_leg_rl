# 换向惩罚与探索噪声诊断

授权：用户要求先查“网络平均动作、探索采样动作、实际腿运动”。仅增加独立诊断脚本和结果；不训练、不改生产文件，不调用子agent。

1. 三个200轮模型，各重放停车/前进/后退原有500帧动作，补存125维history和实际q/qvel。网络平均动作与原action核对≤1e-7，轨迹/目标/力矩/速度与原记录核对≤1e-10。
2. 固定相同history，在每个模型的真实checkpoint标准差下做64条独立噪声采样，使用原动作裁剪和四腿目标映射。不把噪声动作施加到物理轨迹上；这只是固定输入反事实，不是训练rollout。
3. 比较平均动作、噪声动作、固定一帧输入后的噪声动作的0.01rad迟滞换向率和成本。停车额外计算探索标准差倍率敏感性；不更改训练参数。
4. 统计实际目标反向幅度、目标增量RMS、实际qvel/20ms加速度/频谱。用相同频率不同幅度的合成信号验证计数的盲区。
5. 独立NumPy计数器核对共享Torch算法；核验checkpoint、原记录与源码hash；报告事实/推断/未解决问题。不把计数差当成真实训练因果贡献，不宣称已定位全部抽搐根因。
