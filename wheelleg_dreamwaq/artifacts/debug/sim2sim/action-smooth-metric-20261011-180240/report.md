## 计算口径

- 当前公式：S_t = sum((a_t - 2*a_(t-1) + a_(t-2))**2)，使用执行前裁剪到 [-1,1] 的六维标准动作。
- 动作顺序：左前腿 jIJ、左后腿 jIO、右前腿 jAB、右后腿 jAG、左轮、右轮。
- 未乘奖励权重和 control_dt，单位为归一化动作的平方；不是关节位置、角速度或力矩。
- 生产公式见 rewards.py:67，动作裁剪和历史更新见 env.py:645。MuJoCo 部署不计算训练奖励，本分析按训练公式从部署日志复算。
- 相同停车对照：命令 [0,0,0.20]，控制间隔 0.02s，取模拟时间 [2,10) 的 400 帧；最近三帧都在窗口内，因此得到 398 个有效值。
- 逐帧 p95 和一秒窗口平均值 p95 含义不同；将来阈值必须与自适应控制器实际统计方式一致。
- 排除跨 reset 或非连续控制帧。相同停车四腿 RMS 与既有 stationary-comparison.json 一致，误差 <1e-12。

## 对阈值设计的影响

保持六维公式时，总指标驱动的自适应增益主要受轮动作变化支配；左腿仍受相同增益惩罚，但局部改善未必明显改变总指标。现有证据不支持直接设定正式阈值，或保证通过 ROGER 能同时改善机械抖动和跟踪。

将来确定阈值时，需要合格运动片段的实际抖动/跟踪验收，并明确增益控制器统计窗口。此轮未选择阈值，也未接入 ROGER。
