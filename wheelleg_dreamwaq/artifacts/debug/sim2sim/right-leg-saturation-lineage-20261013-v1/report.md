## 4. 相同输入下，负向偏移也跟随权重变化

补充输入来自已有 85% MuJoCo 站立 history，选 90 个相同的五帧输入；再加入同一个正式 reset history。对所有模型使用相同输入，仅替换 checkpoint 网络权重。

同一批输入中，右腿 raw 输出随原始训练权重呈明显负向偏移。原始第 1 轮接近零；第 101 轮在这些较晚策略状态上已经出现明显负向输出；第 1000 轮进一步变负。该固定输入试验只检查网络响应变化，不能代替各模型自己的闭环轨迹或 Isaac 训练动作。

控制器对不同 checkpoint 使用同一个映射；右腿 -1 不是针对右腿写死的输出。网络输出低于 -1，之后才由原动作边界裁剪。原始第 1000 轮和当前 85% 在统一 reset、尚未执行第一个物理步时，两个右腿 raw 输出已经低于 -1。

当前 mean 输出的负值不等同于输出层 bias 被硬编码为大负数：原始模型右腿输出层 bias 只在约 0.06 到 0.04、0.009 到 -0.023 的范围变化，主要负向输出来自完整网络计算。该观察不单独定位 encoder、hidden layer 或某类观测的训练诱因。

## 5. 奖励及预算来源也能接上这条链

原始 run-03 的 checkpoint 没有腿换向或腿加速度增益状态；训练 TensorBoard 也没有对应自适应项日志。原始持续右腿饱和早于这些试验，不由 85% 设置首次引入。

原始训练中，结束于第 101、第 201、第 1000 轮的各 50 轮日志，总单步加权奖励平均分别约 -0.09216、+0.02260、+0.04649。期间速度误差下降、phi0 不对称罚分增加。它说明训练总体目标在改善的同时，没有排除当前观察到的不对称行为；这不是逐项奖励的学习因果归因，也不是同一状态下的奖励对照。

原 rewards.py 惩罚实际运动、六维已裁剪动作差分、phi0 不对称和实际关节软限位等；没有直接惩罚 raw 动作超过 [-1,1] 的幅度或长期动作饱和本身。右腿裁剪后的角度目标仍处于机械软限位以内，因此 dof_pos_limits 不会仅因为动作为 -1 而扣分。只要裁剪后动作与历史相同，-1.1 和 -5 可映射为相同目标；这些 reward 不能直接区分 raw 超界幅度。这解释了现有目标允许这种行为的一个机制，尚不能证明它是唯一学习原因。

重新从旧 baseline 三场景的 24 个一秒窗口计算 pooled p90，得到：

B0 = [40.1703144886371,38.36718525327239,7.036219002293553,4.973546161740354] rad/s²。

与正式试验代码常数最大差仅 4.04e-11。所以左右预算差异不是抄错数或算错单位：参考本身就是左腿活动、右腿目标固定的旧策略。原试验计划已注明它不是健康或安全标准。本次补充了这条来源与新罚分分配之间的关系。

可以连起的证据链为：
旧策略已采用右腿固定目标
→ 参考轨迹右腿实际运动较小
→ 按各关节自身参考缩放后，右腿预算较低
→ 85% 训练中右腿归一化超额主导罚分和全局增益封顶。

最后一项数值依据上一轮独立核对报告；它解释当前试验罚分分配，不能倒过来解释原始第 201 轮为何形成饱和模式。
