# 腿部抽搐指标追查（2026-10-11）

本次只新增诊断日志、计算结果和图，没有改变奖励、动作、命令、物理模型、网络、正式架构或训练设置。保留现有六维 action_smooth；四腿分组只是离线分析，不是已经批准的奖励修改。

结论：停车时左腿存在持续周期振荡，策略指令和实际关节速度共同出现约 **8.8Hz** 的峰值。腿动作二阶差分能反映当前左腿的这类变化；实际关节角加速度能补充检测“指令固定但机械仍运动”的情况。这支持同时保留指令侧与实际运动侧的诊断，尚不支持直接指定 ROGER 合格阈值，也没有定位抽搐的根因。

## 检查对象与算法

四个腿关节按现有 canonical 顺序：jIJ（左前）、jIO（左后）、jAB（右前）、jAG（右后）。没有把轮动作混进本次四腿分组；生产奖励仍覆盖四腿和两轮。

指令指标沿用现有公式：
S腿 = Σ四腿(a_t − 2a_(t−1) + a_(t−2))²。
a 是裁剪后的归一化策略动作，值域 [−1,1]；S 是未乘奖励权重、未乘时间步的原始量。左右两组和四个单关节分别统计。

实际运动指标：
α = (控制周期结束的实际角速度 − 周期开始的实际角速度) / 0.02。
每个关节报告 sqrt(mean(α²))，单位 rad/s²。这是每20ms的平均角加速度，不是MuJoCo每1ms的瞬时qacc；两种数值分别保存，没有混用。

固定停车、前进、后退记录均10s，去掉初始0–2s。为保证三帧动作都在分析片段内，最终每段398帧（2.04–10s），比较指标使用同一组帧。键盘片段按原有稳定命令分段，去掉各段最初2s；没有跨reset取差分。全部共4306帧。

频率分析使用50Hz控制采样、去均值、Hann窗和FFT，检查全部正频率，没有预设“超过多少Hz算抖”的门槛。1s统计窗不重叠；这些窗是同一轨迹中的描述性样本，不是独立实验。

此前六维action_smooth诊断已发现，新1000轮停车的总值约98.8%来自轮动作。这次把腿单列，才能看到腿的变化。这里没有否定轮动作的平滑需求，也没有把轮端奖励删除。

## 持续振荡与正常换向的区别

新1000轮固定停车时，左前和左后策略动作的主峰、实际关节角速度的主峰都在 **8.79397Hz**。键盘停车记录对应约8.72Hz。停车没有速度命令切换，因而这部分持续周期变化不能仅用正常刹车或换向解释。

[停车四关节时序](parking-aligned-traces.png)逐列展示指令、目标与实际位置、实际角速度、实际角加速度。各关节位置图使用相同跨度，速度和加速度图使用相同坐标范围，避免小振动被自动缩放成同等幅度。[停车频谱](parking-spectrum.png)各通道分别归一化，只比较频率，不能据此说两条信号幅度一样。

固定前进 +1m/s 和后退 −1m/s 的左腿实际运动峰值约10Hz。后退的原始动作包含慢漂移，动作主峰可落在低频，不能机械地宣称所有场景“动作主峰都在9Hz”。

## 两种指标各自能看到什么

停车固定测试的1s窗中，左腿动作平滑值与实际左腿加速度合成RMS的相关系数约0.979（7窗）；键盘停车约0.950（24窗），键盘+0.2m/s约0.928（13窗）。旧1401轮停车只有约0.332（7窗）。它们是闭环轨迹中的关联，不是通用的抽搐分类器或根因证据。

[两个指标的对应关系](indicator-association.png)

当前记录中右侧两个策略动作一直裁剪为−1，所以右腿动作二阶差分为0；实际角加速度仍为约6.53、4.80rad/s²。**右腿指令平滑为0，不代表右腿完全不动，也不代表其姿态和控制方式健康。** 不能直接把右腿0当作左腿应该达到的阈值。

## 限制腿动作是否会损害轮端平衡

存在这种风险。腿部姿态、重心调整与轮端控制共同影响平衡；如果动作平滑或实际加速度惩罚过强，策略为刹车、换向或恢复平衡所需的快速腿动作也会付出过高代价。这是需要后续训练验证的风险，本次诊断没有证明某个惩罚强度一定安全或一定有害。

本次没有新增腿动作硬限制。将来即便采用ROGER，定义可接受抖动水平与权重调节也不能替代平衡验收。应同时看速度误差、roll/pitch、摔倒、腿与轮动作／力矩饱和，并对命令切换与持续停车分别解释；“腿变静但容易倒”不能算成功。ROGER不会自动辨别哪次动作是必要的救车动作。

就现有证据而言，可以继续讨论“腿动作分组指标作为调权对象、实际腿角加速度作为核验指标”，但还没有批准奖励拆分或选定τ。用户此前要求保留六维公式；若改变生产奖励的覆盖范围，需先明确该设计，而不能把本次四腿分析直接当成已实施的修改。

## 阈值尚缺的证据

现有键盘记录没有M标记或人工标出的可接受／不可接受片段；同种子一次新旧比较也不足以标定通用门槛。当前可以量化振荡强弱，不能声称40或6rad/s²就是合格线。

下一步可在相同命令和姿态条件下标出“可以接受的平稳片段”及“明显抽搐片段”，用同样公式检查能否区分，同时核对速度与平衡是否合格。右腿数值只能作为当前运行的参考，不能直接当作健康标准。此次尚未检查出CENet、策略、PD或接触反馈中究竟哪一项引起振荡。

## 数据一致性和修改范围核验

前进、后退、换向旧评估日志没有实际腿速度，因此用原策略、原模型、原指令补录三段各500帧诊断。补录与原评估逐帧核对：六维原始动作、整车vx、yaw rate、base height、当前命令差异均为0；前后固定命令的裁剪动作直接对照旧列，换向旧日志没有裁剪动作列，改为对照旧原始动作裁剪至[−1,1]后的结果，差异也为0。补录未改变既有表现。
