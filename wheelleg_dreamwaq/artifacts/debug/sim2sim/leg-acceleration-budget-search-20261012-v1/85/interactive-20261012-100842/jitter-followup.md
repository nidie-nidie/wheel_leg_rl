# 85% 候选：交互可视化抖动复查

本记录补充本轮数值对照报告。85% 候选仍有明显抖动，不能判为稳定版本；此前角加速度统计量下降约 35%，不能等同于可见抖动已解决。

## 数据和方法

模型为 budget85 的 model_199.pt，完成 200 iteration，种子 41882943。分析刚才的 42.4 秒交互记录：2120 个控制周期、42400 个物理步。控制周期 0.02 秒，物理步长 0.001 秒，每个控制周期 20 个物理步。

主分析区间为模拟时间 2—20 秒，共 899 个记录样本，前进和转向命令均为零。26—42 秒的停车段作为补充。采用实际关节角、角速度、策略动作、电机目标和力矩记录，频率来自去均值、Hann 窗的频谱主峰。P5—P95 角度范围不是峰峰值或安全阈值。

已核对 CSV 时间增量、每周期物理步数量，并验证六个关节的物理步速度变化累加与对应控制周期速度变化一致。未改变模型、奖励、控制器或策略。

## 结果

- 左前驱动关节 jIJ 的主要抖动频率约 10.96 Hz，实际角度 P5—P95 范围约 1.97 度；其目标角度也在约 10.96 Hz 变化。
- 左后驱动关节 jIO 的主要抖动频率约 11.12 Hz，实际角度 P5—P95 范围约 2.25 度；其目标角度也在约 11.12 Hz 变化。
- 左、右轮目标速度达到正负 25 rad/s，目标方向平均每秒切换约 22.3、30.6 次。轮子力矩达到输出上限的物理步占比约 72.7%、55.0%。
- 两个右腿动作在该停车段均持续处于负向动作裁剪边界，目标角度保持不变；它们的实际角度波动较小。
- 前进速度平均绝对误差约 0.031 m/s，偏航角在停车段累计变化约 -43.7 度。小的前进速度误差不能反映高频来回动作和无命令转向。
- 26—42 秒再次停车时仍出现无命令偏航，累计变化约 -30.6 度。

## 结论边界和下一步

这版没有解决用户看到的抖动和不稳定表现。记录表明策略输出、电机目标和实际运动均存在持续变化，轮子也在快速正反切换。

这些是同一次闭环运行中的共同现象，不能单凭相关性断定轮子导致左腿抖动、左腿导致轮子振荡，或 CENet 估速是根因。下一步应针对零命令下持续正反轮指令，追查输入观测、估速反馈与输出的关系，并同时检查右腿长期动作饱和；目前没有足够依据继续收紧腿部阈值或扩大训练。
