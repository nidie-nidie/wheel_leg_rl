# 85% 候选停车振荡：反馈隔离诊断

本轮已经定位到振荡依赖的两条关键反馈路径，但尚未确定这种控制模式最初由训练形成，还是由 sim2sim 的动力学差异诱发或增强。当前证据不支持直接屏蔽反馈，也不支持仅靠继续收紧腿部加速度阈值来解决问题。

## 对象、范围和验证

使用刚才可视化的 budget85/model_199.pt，完成 200 iteration，种子 41882943，Actor SHA256 为 0314C48A295EAA6E99709FE600FA717B264814BAFF02444AF8D62C1C699896F2。使用正式 PhysicsV5 MuJoCo 模型，目标命令固定为 vx=0、yaw=0、height=0.20m。

2120 个控制帧、42400 个物理步的用户记录已逐帧重放，history、动作、前后关节状态、速度、力矩和时间误差均为零。history 滚动和上一动作时序误差也为零。独立按 CSV 与 manifest 核对腿角归一化及轮速符号/缩放，通过；未发现输入 NaN/Inf 或相关归一化裁剪饱和。

从原轨迹模拟时间 2、6、10 秒分别复制完整 MuJoCo 状态，包括求解 warm start、五帧 history 和真实上一动作。每个分支运行 5 秒，在给网络的输入副本上逐项替换反馈。电机、接触、重力、关节、动作执行和控制周期均保持原配置。反馈固定值使用该起点之前 1 秒的记录均值。

第一组 27 个分支，第二组角速度细分 15 个分支，共 10380 个控制周期、207600 个物理步。稳定段统计通常省略前 1 秒；触发失败的分支提前停止，其统计时长较短，不可当作成功策略。

94 个受保护文件哈希保持不变。新增的脚本、统计和图片均在本诊断目录；未训练，未修改生产代码、USD、奖励或控制参数。

### 估速偏差不足以解释主要抖动

真实速度替换让停车速度误差约降低 45.4%，但左腿合并加速度 RMS 指标只下降约 1.3%，轮子快速换向保持。这里的结论仅针对 CENet 输出的三维速度分量；它不排除 encoder 的 context 路径参与振荡。

### 左腿输出强烈依赖上一帧轮动作反馈

固定五帧中的上一帧轮动作，使左腿合并 RMS 指标下降约 81.5%，但轮子换向升至约每秒 41 次。真实轮子仍在执行网络新输出的动作，因此不能把左腿抽动简单解释成轮子的物理振动直接传到了腿上。网络读取“自己刚给轮子发了什么指令”的路径本身，对左腿持续修正有很强影响。

合并指标按三个分支中两关节 RMS 的平均值向量范数计算，表中保留两关节各自结果。

### 轮子换向与 pitch 平衡反馈有关

固定 pitch 角速度，即“身体前后倾斜的变化速度”，明显降低轮子换向次数，同时平均停车速度误差增至约 0.297 m/s，三个分支中一个触发 tilt 失败。固定 roll 或 yaw 角速度时，轮子仍持续快速换向。

这说明该策略在本次 MuJoCo 状态上依赖 pitch 角速度反馈维持平衡；不能据此判断每次大幅换向都是必要动作，也不能直接删除这项观测。

### 电机执行力矩与现有公式一致

对用户记录的全部 42400 个物理步独立重算四腿 PD 和两轮速度控制力矩，使用与控制器一致的 float64 计算及 ±18/±9 Nm 输出上限。六关节“重算值—命令力矩”最大误差均为 0 Nm，“实际 actuator 广义力矩—命令力矩”最大误差也均为 0 Nm，所选关节 qfrc_applied 均为 0 Nm。

这验证了当前电机执行边界；正常接触力、闭链约束力、被动阻尼及惯性仍会影响实际运动。该检查不能证明 Isaac 与 MuJoCo 的动力学响应相同。

### 持续振荡需要物理状态反馈参与

从三个 MuJoCo 快照提取物理特征并保持不变，仅继续迭代策略和真实裁剪动作历史，六秒计算中最后五秒没有持续正反轮动作切换，动作逐帧变化 RMS 小于 0.001。该结果来自固定物理输入的离线网络推理，不是机器人站稳实验。

在这些快照上，上一动作的计算递归本身未独立维持原来的振荡；物理反馈加入后形成持续振荡。不能把这一结果推广为网络在任意状态下都不会自发振荡。

## 结论与后续方向

可以确认：当前 85% 策略在 MuJoCo 中存在持续反馈振荡；轮子换向与 pitch 平衡反馈有关，左腿修正对轮动作历史反馈敏感。history/上一动作错位、归一化错误和电机额外施加驱动力矩，在本次核对中没有发现。用真实速度替换估速不能解决主要抖动。

不能确认：振荡最初是训练学出了这种控制方式，还是仿真器物理响应差异使策略过度修正。也没有证据证明直接屏蔽反馈、固定 context 或继续压低腿部阈值可以修好控制。

后续应保留平衡所需反馈，围绕“轮子大幅反复纠偏及其动作历史对左腿的影响”设计对照，并同时验收轮动作变化、实际腿抖动、停车/行驶误差和摔倒情况。生产修改与训练方案应在这条定位结果基础上再确定。
