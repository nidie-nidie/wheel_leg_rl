# 右腿饱和与速度/平稳性深追查

本轮授权：不启动训练、不改训练代码；仅debug目录新增诊断。MuJoCo采集，agent串行讨论。

1. 保持现有PhysicsV5 XML、六维观测/动作与控制不变，比较其他三个原始种子保存的1/101/201/1000轮模型。
2. 检查首次进入饱和时的输入、网络输出与实际目标，区分共同机械偏置和策略学习选择。
3. 以85%候选为固定网络，在debug动作路径比较无处理、腿/轮/全部动作的一阶低通过渡；真实执行的动作照常进入history，轮速传感不掩盖，不加入额外力矩。
4. 先筛选停车/前进/后退/混合命令；有优势才扩大到原八场景与停车换向、长时间验证，不挑只好看的段。
5. 独立复算目标映射、动作处理与指标，记录失败，核对原文件SHA256。
6. 分清证实机制、候选改法和无法从旧checkpoint恢复的训练因果；给出同时速度跟踪和腿平稳的方案及是否已有模型达到要求。
