# 轮共同动作反馈路径定位

目标：在已定位的轮共同动作历史反馈中，区分轮共同输出、轮差速输出、腿输出各自对持续振荡和速度表现的作用，并把训练更新与具体反馈敏感度联系起来。

执行范围：仅debug新增CPU脚本和结果，冻结401模型；平均动作、heading关闭、正式八场景500步、三组切换和正式失败条件保持。GPU已有其他项目6144环境训练，不启动额外CUDA进程。

- [x] 使用真实动作历史，将五帧左右轮上一动作的共同分量从辅助输入中减去，差速分量保持；原始输入与真实动作历史始终保存。
- [x] 分别只改变腿输出、轮共同输出、轮差速输出，并做全部输出干预作为路径对照；轮共同路径取剩余比例0、0.5、0.75，所有其他路径保持原策略。
- [x] 复用已验收的301/401平均动作CSV；新干预用相同初态和控制协议，保存逐步CSV及原始/辅助输入和输出，检验单路径不变条件。
- [x] 分析实际临界更新前后的actor参数和同一批真实输入的反馈敏感度，检查哪类实际更新放大经物理干预确认的路径。
- [x] 独立重算64组路径场景、六组切换、原始动作历史和逐步策略输出，另核查24组局部更新干预场景；118文件指纹保持一致。
- [x] 保留五帧均值、移除快速帧间变化的轮共同输出干预；报告相对旧701的速度缺口与右转问题。
- [ ] MuJoCo候选的Isaac闭环验收；当前其他项目占用GPU，不能宣称跨引擎通过。
- [ ] 使用原GPU算术完成真实318奖励分项严格重建；CPU估计与未归属反向残差已单独记录，严格门槛保持。

数学定义：对每帧上一左右轮动作aL、aR，辅助历史使用(aL-c,aR-c)，c=(aL+aR)/2。原策略输出u与辅助历史输出v共同用于路径干预。仅轮共同输出干预为u_wheels + (1-alpha)*(mean(v_wheels)-mean(u_wheels))，alpha是该历史作用的剩余比例。腿输出和轮差速输出独立使用相同定义。此为冻结策略的运行时因果诊断，未声称等同训练修复。
