## 工程目标

建立一个代码简洁、架构清晰、奖励配置有依据，并能高效训练的轮腿机器人强化学习工程。

期望一次完整演示包含以下过程：

1. 从趴地或其他倒地姿态开始，自主完成起身。
2. 起身后保持车体平衡，并切换到行走策略。
3. 按指令前进和后退，同时保持平衡。
4. 面对外部踢碰等扰动，能够抵抗扰动并恢复稳定。

希望起身能力覆盖各种倒地初态，抗扰动能力尽可能强。具体初态范围、扰动方向、强度、持续时间，以及起身、平衡和行走的成功指标，后续共同确定。抗扰动能力需要在明确的测试范围内验收。

## 当前状态

记录日期：2026-10-29。以下状态依据使用者的实际观察。

- 目前的观察范围仅限仿真，实物能力尚未验证。
- 已在 MuJoCo 中加载训练好的策略模型进行回放控制，亲眼看到机器人能够行走。
- MuJoCo 与 Isaac Sim 中的行走表现尚未确认同时成功。使用者印象是一侧能够行走时，另一侧表现不成功；对应模型、配置及具体失败表现待核实。
- 倒地起身、起身后保持平衡及切换行走策略、抗扰动等环节仍是待完成目标。

对应行走演示的模型、配置和运行条件尚待确认，两个仿真器是否使用同一模型及一致的控制约定也待核实。相关代码的完成程度及已有实验的覆盖范围，将在后续阅读中逐项核实。
