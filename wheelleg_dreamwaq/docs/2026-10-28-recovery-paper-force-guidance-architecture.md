## 1. 本次准备实现的行为

机器人倒地时，训练环境根据机身质心高度给予向上的辅助力。机器人接近目标高度时，辅助力减小。训练进行到规定进度后，辅助力完全撤除。

学习器同时保留两类信息：原有起身任务奖励，以及辅助力使用代价。两类信息分别估计长期影响，然后按论文的罚函数思想形成 PPO 更新方向。使用更多辅助会增加学习目标中的代价。

本次启用范围为辅助力通路。论文中的辅助力矩公式在本文完整列出，运行配置保持关闭，力矩及其代价严格为零。启用力矩需要更新本文件的范围、配置和验收，不能由实现人员自行打开。

Actor 在原五帧本体观测之后额外获得当前辅助系数。部署时，该系数固定为零。起身后继续使用已有行走 checkpoint 和双策略监督器。

本设计复用现有物理动作定义：起身腿部目标为 q_reference + 0.35a，轮速目标为 25a；腿部和轮部力矩能力分别为 18 N·m、9 N·m。原有奖励、惩罚和物理失败检查继续按其契约执行。

## 2. 论文依据与复现口径

主要依据为作者论文 [FTSR，arXiv:2606.14270v1](https://arxiv.org/html/2606.14270v1)，重点为 II-C 式（4）至（8）及 Algorithm 1。

论文明确使用罚函数处理辅助约束，并使用 PPO 优化。本文采用“依据式（5）与式（6）的 PPO 罚函数解释”，同时解释式（8）中无法直接确定的估计细节。它不包含原始 CPO 的二次规划、共轭梯度或可行方向求解器，也不承诺逐回合或逐时刻严格满足预算。

复现范围为辅助力公式与罚函数 PPO 接入。本机六维机构、现有任务奖励和行走状态机继续使用本项目定义；本次不复现作者的八维机器人、教师学生网络及三阶段奖励。因此，后续结果应称为“FTSR 辅助引导的本机适配”，不能称为论文全部实验复现。

## 3. 物理辅助计算

### 3.1 原式与本机实际施力

论文原式：

    a_raw = (1 - exp(-mu * (h_target - h))) * alpha
    alpha = clamp(1 - global_control_steps / end_control_steps, 0, 1)
    F_raw_world = a_raw * Fmax * [0, 0, 1]
    T_raw_world = a_raw * Tmax * log(R_target * R_current^T)

h 为 base_link 刚体质心相对地面的世界高度，单位 m。当前代码中对应 root_com_pos_w 的 Z 分量减环境 origin 的 Z 分量。本文沿用机身刚体质心高度作为本机任务定义，未将它等同于所有运动连杆的整机质心高度。h_target=0.20 m 沿用本机目标，不能套用作者机器人高度。

原式在 h 高于目标时会产生负辅助系数。对于本次“向上辅助”范围，实际施力采用以下明确适配：

    height_deficit = max(h_target - h, 0)
    a_applied = (1 - exp(-mu * height_deficit)) * alpha
    F_submitted_world = a_applied * Fmax * [0, 0, 1]
    T_submitted_world = [0, 0, 0]

在 h 不高于目标的定义域，实际高度函数与论文原式一致；超过目标高度时关闭辅助。这项适配必须写入配置身份，同时记录原式值和最终提交值。禁止静默将原式负号当成额外向下压力。

实际力使用数值稳定的 -expm1(-mu*height_deficit) 计算，属于同一函数的稳定表达。原式诊断在有界日志采样点使用 float64，并先检查指数可表示范围；超出范围时记录 raw_overflow=true、指数和负号，原式数值字段为 null，不执行会溢出的指数。该诊断不能将非有限值带入实际力、成本或 transition，也不能通过截断指数伪造原式值。物理状态或实际施力本身非有限时，继续执行原有立即报错规则。

### 3.3 坐标、施力点与引擎接口

通过名称唯一解析 base_link，禁止假设索引为零。当前控制帧满足 x_control=-y_USD、y_control=x_USD、z_control=z_USD；四元数为 wxyz。向上力直接使用世界 Z，不经过身体姿态旋转。

CAD 链接原点和机身质心存在较大偏移。高度和施力点均以运行时质心为准，不能使用根链接原点代替。

拟在 env.py 的 _apply_action 中，每个 0.005 s 物理子步重新计算并提交一次 instantaneous wrench；随后由场景写入模拟器。优先使用 instantaneous_wrench_composer，明确传入力和零力矩，is_global=true、positions=None。该接口的实际 COM 语义必须通过真实物理验证后确定。

本地 WrenchComposer 同时传入 positions、force、torque 的实现存在位置叉乘覆盖输入力矩及参考系混用风险，因此禁止未经验证直接使用“世界 COM 位置加力矩”的组合调用。若 positions=None 的真实验证不满足 COM 施力要求，则使用经过同帧转换、作用点明确的 PhysX 封装；最终只能保留一个提交入口，并记录选定实现。

API 提交值表示最终写入引擎的命令，不冒充外力传感器测量。文档与日志分别标注 submitted wrench 和独立物理响应证据。

### 3.4 论文力矩的保留说明

本次配置令 Tmax=0，辅助力矩、力矩成本和对应优势均精确为零。

后续启用时，需要单独冻结目标姿态、偏航处理、wxyz 与控制帧转换、SO(3) 的最短旋转及 180 度选轴规则。单独使用两个方向的叉乘不能覆盖完全倒立。论文的 Tmax 直接乘旋转向量，在角度超过 1 rad 时不构成力矩范数上限；若增加外部力矩限幅，必须明确登记为物理适配。

## 4. 控制步成本与时间进度

设一个控制步的四次最终提交外力为 F_t,1 至 F_t,4：

    c_force[t] = (norm(F_t,1) + ... + norm(F_t,4)) / 4

成本单位为 N。采用本文明确的线性幅值标量化，不平方，不额外乘 dt。当前方法的折扣和每控制步成本共同定义学习尺度，改变控制周期需要新配置身份。

本控制步的辅助统计必须在自动 reset 前冻结。runner 从 extras 的版本化 guidance 数据中读取本次 transition 的成本，不能从 reset 后的新状态倒推。

global_control_steps 表示整批 env.step 的调用次数，不乘并行环境数量，不随单个环境回合重置。一个 PPO 更新完成 24 个整批控制步；end_control_steps=3000*24=72000。四个物理子步共享当前控制步的 alpha，高度则逐子步更新。

在第 k 个控制步开始时，使用 alpha_k=max(1-k/72000,0)。该控制步实际结束后再令 k 加一。reset 和只读观测均不推进 k。

## 5. PPO 罚函数计算

### 5.1 分别估计任务价值与辅助成本价值

原有奖励 r_t 不额外扣除辅助成本，奖励 critic 预测原任务的折扣回报。成本 critic 独立预测辅助成本回报。禁止同时在奖励中扣成本，又在优势中加入同一惩罚。

每类信号 x 分别使用 GAE：

    delta_x[t] = x[t] + gamma * alive[t] * V_x[next] - V_x[t]
    A_x[t] = delta_x[t] + gamma * lambda * alive[t] * A_x[next]

真实终止时 alive=0，奖励和成本均不做终态 bootstrap；仅到达 24 步采集边界而未终止时，使用相应 critic 的下一状态值。

成本 critic 学习 c_force/S_F，S_F 为固定名义重量 43.127251624 N，并将运行时实际选择值写入配置。其训练目标为 R_cost_scaled=A_cost_scaled+V_cost_scaled，目标在本次更新前冻结。Actor 使用的成本优势必须乘回 S_F，保持 beta 对物理单位成本的含义。禁止用每轮变化的标准差替代固定单位缩放。

### 5.2 从论文式（5）到 PPO 更新

按旧策略采集数据后，固定奖励和成本优势，保留策略比率：

    rho(theta) = pi_theta(action|observation) / pi_old(action|observation)
    J_cost_surrogate(theta)
      = J_cost_old + mean(rho(theta) * A_cost_physical) / (1-gamma)

rho 保留梯度；优势和 J_cost_old 作为采样估计固定。有限 rollout 的样本均值用于近似论文旧策略状态分布下的期望，不宣称等于无限时域的精确分布积分。不能提前计算 mean(A_cost).detach()，再将它广播到全部样本中。即使旧策略下成本优势均值接近零，rho 加权项对策略的梯度仍可能非零。

对于同一批样本，下面未标准化、未裁剪的 mean(rho*B) 与式（5）对应经验罚函数目标具有相同策略梯度。实际 PPO 随后执行一次统一标准化和式（6）的裁剪；该近似优化过程不宣称在整个参数空间保持原目标梯度一致：

    B[t] = A_reward[t] - beta_force * A_cost_physical[t] / (1-gamma)
    B_normalized = (B - mean(B)) / (std_population(B) + 1e-8)
    L_policy = mean(min(rho * B_normalized,
                        clip(rho,1-epsilon,1+epsilon) * B_normalized))

标准化覆盖整个 rollout 的时间与环境维，只执行一次。使用总体标准差。成本优势不单独按动态标准差标准化，以免改变固定 beta 的含义。

当前 RSL-RL 的 PPO.compute_returns 会自动标准化奖励优势。新增 guidance 路径必须直接以 normalize_advantage=false 计算原始奖励 GAE，并关闭 normalize_advantage_per_mini_batch；在混合之后统一标准化。奖励 return 保持原任务目标，不被混合优势覆盖。旧 V2 普通 PPO 路径继续使用原行为。

当前提案 beta=0.00001、gamma=0.99，因此 actor 混合中的成本系数为 0.001。实现必须保留该 1/(1-gamma)，不能将 beta 直接当成普通奖励扣分权重。

PPO 的概率比率裁剪是学习器更新规则，与机器人动作裁剪分别定义，不对起身采样动作和部署输出增加限幅。

### 5.3 与式（8）字面写法的区别

本设计明确优先采用式（5）及式（6）的可执行解释：

1. 期望在策略损失聚合阶段计算，保留重要性比率；不先将标准化成本优势求均值。
2. J_cost_old 和 d 在式（5）中对本次策略更新为常数，记录在 surrogate 数值中，不广播进 clipped advantage。这样避免将状态无关常数置于 PPO clip 内造成额外效应。
3. 式（8）中的逐时刻 J 项未被论文明确为瞬时成本或成本回报，本文不伪造该定义。因而本实现不能标为“式（8）逐字复现”。
4. 成本 critic、标量化、统一标准化顺序均为补全实现细节的明确选择。
5. beta 固定，不加入作者 Algorithm 1 未给出的自适应乘子更新。

若用户要求严格复现式（8）字面实现及作者每个训练数值，当前公开材料不足；需要作者补充 J 项语义、成本 GAE、期望维度和标准化顺序。该限制不影响本文所定义 PPO 罚函数方案的可实现性。

### 5.4 价值模型与优化器

奖励网络和成本网络各自使用 [256,128,64]、ELU，分别输出任务价值与一个辅助力成本价值。任务网络使用原 PPO 优化器；成本网络使用独立 Adam，学习率初值 0.001、梯度范数上限 1.0，成本价值损失使用固定单位缩放后的 return MSE。

优势和目标由更新前的网络计算并冻结，不能在每个 mini batch 重算。成本网络更新不能通过优势反向传播到 actor；两个价值模型的目标均与对应数据来源一致。成本价值优化次数与 PPO 的 5 个 epoch、4 个 mini batch 保持一致。每个 mini batch 的 actor、奖励和成本数据由同一次索引生成，禁止两套 storage 分别随机排序后按行拼接。

环境施力与成本使用该 transition 的 alpha_t；成本价值评估按输入状态的 alpha 逐样本处理，alpha=0 的样本输出零。Storage 同时保存 alpha_t 与 bootstrap 所需的 alpha_next。只有 alpha_t=0 的样本，其成本优势与 actor 辅助项精确归零；不能根据更新时的全局 alpha 清除整批历史优势。

在 k=71999 到 72000 的 transition，当前微小辅助成本仍计入，下一状态成本 bootstrap 为零。最后一个含辅助的 rollout 继续使用其真实成本优势；后续全 alpha=0 的 rollout 才完全退化为无辅助更新。

### 5.5 本机奖励单位与提前失败风险

当前 rewards.py 将连续任务奖励乘控制周期 0.02 s，终止失败项为 -10。辅助成本按本文定义使用 N 幅值且不乘 dt。因此，论文的同一个 beta 数值不能保证在本机获得相同奖励与成本比例。

用于量级检查的未裁剪、未标准化折扣目标为：

    G_penalized = sum(gamma^t * r_t)
                  - beta_force/(1-gamma) * sum(gamma^t * c_force[t])

这只是本文经验罚函数方向的尺度诊断，不等同于实际 PPO 多轮更新后的目标值。

按名义 Fmax=21.5636 N、gamma=0.99、最长 400 步，辅助惩罚上界为：

    P_max = beta_force/(1-gamma) * Fmax * (1-gamma^400)/(1-gamma)

若照搬 beta=0.001，该上界约 211.77；本机提案 beta=0.00001 时约 2.12。另以 h=0.15 m、alpha=1、持续 100 步作静态量级推演，辅助力约 13.6308 N，两个系数分别对应约 86.41、0.8641 的折扣辅助惩罚。这些数值来自明确假设，不能当作真实轨迹结果。实际 alpha 在回合内下降，因而在相同固定高度假设下，该固定 alpha 推演也构成相应上界。

因此本机采用 0.00001 提案初值，保留论文罚函数计算结构，并明确登记系数适配。固定 S_F 只改善成本 critic 的学习单位，不改变此处 actor 惩罚量级。

2.12 小于 10 只消除了最明显的量级失衡，不能证明所有状态下继续尝试都优于主动失败。长训练前必须用配对初态的真实短轨迹检查立即物理失败、持续尝试及超时的完整任务奖励和辅助目标排序，并按初态记录终止与回合长度。有效对照数量必须大于零，缺少对照时记录 inconclusive，不能当作通过。快慢成功排序在具备实际成功轨迹后独立验证；当前成功门控未标定，初始训练报告明确登记该项不可用。若新增辅助成本逆转已观察到的持续尝试与早期失败排序，应保持长训练未启动，更新本文参数并重新验算；不能通过隐式改奖励、改终止或漏记成本掩盖问题。

alpha 在采样动作前属于当前状态；下一状态 critic 使用下一控制步的 alpha。控制步计数推进、观测缓存失效和历史更新必须统一处理，禁止同一状态的 actor 与 critic 获得相差一步的辅助进度。

具体时序采用一个固定入口：_pre_physics_step 保存 alpha_t、清零本次四个子步累计并设置 pending transition；四个子步执行完成后，在 _get_dones 开头、首次调用 _prepare_observation 之前完成辅助 transition 冻结并推进 k。此时 Isaac 已推进 common_step_counter，随后原 _prepare_observation 只追加一次本体历史，并拼接 alpha_next。不得在 _get_dones 结束后再次使整份观测失效并重复追加同一帧。只读观测和局部 _reset_idx 仅重建或读取缓存，不完成 pending transition，也不推进 k。

额外 alpha 使策略明确知道当前训练帮助强度；当前观测仍包含原有部分可观测性，不能宣称仅凭 IMU 和该系数获得完整物理状态。该标量由训练程序提供，部署恒为零，不需要新增实机传感器。

原 RecoveryContractV2 固定 critic 34 维，不能在该契约名下静默写入 35 维网络。新分支新增 GuidanceTrainingContractV1，完整登记 111/35 维与算法定义，同时引用 V2 的物理动作、时间和奖励字段。旧模型继续按原契约加载。

| --- | --- |
| training/recovery/guidance.py（新增） | 原式参考计算、实际向上力适配、全局撤除与 GPU 张量缓存 |

每个控制步的数据流：

1. 使用 k 计算 alpha，构造当前观测，保存奖励和成本价值估计。
2. PPO 采样六维动作，按当前动作契约设置执行器目标。
3. 四个真实物理子步分别计算、提交并累计最终辅助力。
4. 物理状态更新后，在 _get_dones 的观测准备前核验四个子步已完成；冻结成本、alpha_t 和对应回合身份，清除 pending 标志并推进 k。
5. 按原时序准备一次本体历史，计算终止与原任务奖励；局部自动 reset 只清对应环境，不改变全局撤除进度或已冻结 transition。
6. 返回下一状态的 111/35 维观测，其中辅助尾项使用 alpha_next；runner 将本次 transition 成本写入独立 storage。
7. 24 步后分别计算奖励、成本 GAE，混合后标准化并执行 PPO 与成本 critic 更新。

## 10. 实施验收

### 数学与张量

- 独立 NumPy 参考核验原式高度、时间、力与姿态公式；覆盖达到目标、超过目标、撤除边界和非有限输入。
- 有限高位状态下实际辅助精确为零；原式诊断超出数值范围时不污染有效 transition。

- 验证标准化成本优势均值接近零时，mean(rho*A_cost) 对策略仍能产生非零梯度。
- 固定单位缩放前后的 actor 成本梯度一致；已知样本的 gamma 系数及一次标准化结果一致。
- 真实终止无 bootstrap，未终止采集边界有 bootstrap，局部 reset 不串回合。

- beta=0 时，新输入规范下的学习器退化为对应普通 PPO；V2 禁用路径与原实现分别做回归。

- 两个环境只重置一个，另一个的状态与辅助进度连续。
- 原有闭链、接触、几何失败和实际电机力矩检查持续有效。
- 关闭辅助后，提交力、矩、成本、辅助观测和 actor 成本项精确为零。
