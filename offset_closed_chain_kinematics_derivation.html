一句话解释发生了什么

PDF： 理想主动杆角 φ=[φ1, φ4]ᵀ ──理想五杆 f──▶ y=[L0, φ0]ᵀ
XML： q=[q前,q后]ᵀ → J,L,P → 第一次闭链求 M → W=P+Sb(M−L) → y=[L0,φ0]ᵀ

共同部分： [F0, Tp] ── J_Hᵀ ──▶ 两台关节电机力矩

所以不是“偏置机构不能做 VMC”，而是目前把 q前/q后 只经过负号和固定 offset 后，直接当作 PDF 的 φ4/φ1。这在一个姿态附近可以接近，但不可能在整个构型域完全一致。

两个模型必须分开读：完整 XML 基准保留导出文件中的全部小数，用来验证闭链树和 MuJoCo；4.3 的 CAD 设计模型则按机械约束强制 I、L、P 共线并令 P→W∥L→M。旧的“微米级简式误差”属于保留 XML 小角度的基准化简，不能再冒充 CAD 约束模型的误差。两者约 0.271 mm 的名义差异应通过 CAD/XML 对齐解决。
重要的量级判断： 名义 XML 与理想五杆确实有构型相关误差，但扫描 L0=0.15…0.42 m、φ0=70…110° 后最大只有约 1.616 mm、1.102°。它值得修正，却未必能单独解释“长腿完全对不上”或猛烈磕头；坐标、MIT/VMC 叠加、饱和和软约束还要分开查。

3. PDF 的普通五连杆，与 XML 的偏置串腿

为什么 C 是两圆交点：主动杆角给定后，B、D 的位置已经确定。被动杆 BC 的长度恒为 l₂，所以 C 到 B 的距离只能等于 l₂，即 C 必须落在“圆心 B、半径 l₂”的圆上；同理 DC 长度恒为 l₃，所以 C 还必须落在“圆心 D、半径 l₃”的圆上。两个条件同时成立的位置，只能是两个圆的交点。图中 C 与 C′ 是两种装配支路，实际轮轴只取与当前机械装配连续的那一个。

PDF 隐含的假设

  • 电机轴直接驱动长度为 l1、l4 的主动杆。
  • 电机角与 φ1、φ4 之间只差固定零点和符号。
  • 轮轴 C 由标准五杆的一个圆交点得到。

当前 XML 的事实

  • 前电机 jIJ 驱动 I–J；随后是单杆 J–M、复合刚体 M–L–K、单杆 K–N。
  • 后电机 jIO 驱动刚体 I–L–P；输出刚体 P–N–W 把运动带到轮轴 W。
  • equality 的 L、N 两个闭链铰把两条树枝重新闭合。

为什么固定 offset 不能完全解决

残差首先留在轮轴位置，不是凭空留在某个控制器参数里。在同一个二维腿平面内定义四个带箭头的当前位移向量：

δ→IL=IL→,δ→LM=LM→,δ→IP=IP→,δ→PW=PW→

小机构端点和真实轮轴相对同一个原点 I 的位置分别是：

r→M=δ→IL+δ→LM,r→W=δ→IP+δ→PW

如果偏置机构真的是“小机构经过一次固定旋转、再放大固定倍数”，那么必须存在同一个二维相似变换 S=kR(δ)，同时满足：

δ→IP=Sδ→IL,δ→PW=Sδ→LM⟹r→W=S(δ→IL+δ→LM)=Sr→M

此时无论腿怎么运动，M 经同一个固定比例和固定角度都正好落到 W；固定符号、比例和角度 offset 才能全工作域成立。现在以 CAD 设计约束为准：I、L、P 严格共线，P→W 与 L→M 严格平行，所以两段都不再引入额外固定角，只剩两个不同的长度比例：

Sa=kaI2,ka=ℓIPℓIL=2.217
Sb=kbI2,kb=ℓPWℓLM=2.243

两个比例仍相差约 1.203%，所以整套机构并不是同一个比例尺下的严格相似放大。若错误地用第一段比例 ka 放大整个内层点 M，则：

r→^W=kar→M,r→W−r→^W⏟轮轴位置残差 e→W=(kb−ka)δ→LM

带箭头的 δLM=L→M 会随腿姿态转动，因此这个残差向量也随构型转动。固定角度 offset 最多让某一个姿态看起来对齐，却不能消除 ka≠kb 造成的全工作域比例误差；这才是本节“固定 offset 不能完全解决”的核心。

这并不否定后文的一次闭链简式。错误的是强迫整个点 M 满足 W=kM；推荐式保留真实起点 P：W=P+kb(M−L)。又因为 P=kaL，也可写成 W=kbM+(ka−kb)L。它精确保留了两级比例差，同时省掉第二次圆交。
数值量级：在同一组 q 下比较理想五杆与 XML 精确闭链，扫描域内二维轮轴位置差最大约 8.208 mm；换成控制变量后，最大约为 ΔL0=1.616 mm、Δθleg=1.102°。它证明固定 offset 不是严格全域解，但这个量级本身仍不足以自动解释几十毫米误差或猛烈磕头。
另一个直接判据：若强行让理想五杆在每个竖直腿姿态都复现 XML 轮轴，反算所需前侧固定角偏移：L0=0.150、0.200、0.250、0.300、0.350、0.400 m 时分别为 −6.021°、−5.460°、−5.096°、−4.831°、−4.619°、−4.428°。真正的固定 offset 应在所有姿态得到同一个数；这里漂移约 1.593°。

4. 当前状态正解：从 q 到 W、L0、φ0

以下先对 XML 的名义左腿定义主动坐标；右腿按第 2 节接口表把 [jAB,jAG] 排成同样的“前、后”顺序：

q→=[qfqr]=[qjIJqjIO]

4.0 XML 的 q=0 与实车电机零点不是同一个概念

vIJ…vPW 保存的是 CAD/XML 刚体几何：固定杆长、固定点距和固定夹角。它们可以在 XML 的参考构型 q=0 中表达，但并不要求实车真的能停在这个姿态。实车每个控制周期首先要把编码器角映射成模型角：

qmodel,i=siqenc,i+bi=si(qenc,i−qenc,i*)+qmodel,i*
qmodel 到底是什么：它是“当前关节相对 CAD/XML 参考构型转了多少”的模型广义角，单位 rad。它既不是原始编码器读数，也不是杆 I→J 或 I→L 相对 +s 轴的绝对方向角；绝对杆角还要再加参考方向，即 φ4=qmodel,f+αIJref、φ1=qmodel,r+αILref。
量含义怎样确定
si∈{+1,−1}编码器正方向到 XML 关节正方向的极性固定其他条件，小角度正/负转动并比较模型点的运动方向
qenc,i*某个可重复标定姿态下的实车编码器读数硬限位、精密夹具或 CAD 可测姿态；仅“拉到不动”只能保证可重复，不能自动说明它是 XML q=0
qmodel,i*同一个物理姿态在精确 XML 模型里的关节角由 CAD 对齐、MuJoCo qpos 或精确逆解得到
bi编码器零点与模型零点之间的常数偏移bi=qmodel,i*−siqenc,i*

因此实车零点不同并不要求重算 vML、vMK 等刚体向量；只要真实连杆几何与 XML 一致，修正的是输入坐标 qenc→qmodel。只有加工尺寸、轴心位置或固定夹角与 XML 不一致时，才需要更新几何向量。

当前工程边界：J0_ANGLE_OFFSET…J3_ANGLE_OFFSET 原本服务于“电机位置→理想五杆 φ1/φ4”的旧坐标变换，不能未经标定就当成精确 XML raw-q 的 b_i。硬限位自动标零保存的是电机参考原点，不会自动完成上述模型角对齐。最少要用第二个独立姿态复核；若不同姿态反算出的 bi 不恒定，问题就不再是单一零偏。
当前副本与活动固件确实相差约 5.078°：活动固件常量显示为 ±0.192 rad，而 mujoco_control_extract 副本显示为 ±0.103 rad，两组常量的绝对值相差 0.089 rad（5.078°）。但是这个差只表示“两个源文件里的旧常量不一致”，而 b_i 的定义是“同一个真实物理姿态下，模型角与编码器角之间的差”。只有确认两套常量使用同一电机、同一编码器零点、同一正方向、同一前后顺序，并且都直接映射到同一种模型角时，差值才可能并入 bi。当前旧常量服务于理想五杆 φ1/φ4 坐标，条件并未成立，因此不能直接令 bi=±5.078°。
当前自动标定还有一个代码风险：UpdateCalibrateStatus() 使用 velocity > CALIBRATE_STOP_VELOCITY 判断电机仍在运动，没有对速度取绝对值；但四台校准命令里有两台是负速度。因此负向高速运动可能被提前判成“已停止”并保存零点。当前 ENABLE_CHASSIS_CALIBRATE=false，现有自动标定结果也不能作为 XML 零位已经对齐的独立证据。

4.2 完整 XML 基准中的两次圆交（理解机械约束用）

这一节是完整基准，不是推荐实时路径。它说明 XML 的 K、N、equality 怎样闭合，并为 4.3 的平行四边形化简提供独立真值。只关心最终控制实现时可以直接跳到 4.3：运行时只保留第一次 J/L→M 圆交。
先给出完整顺序：圆交不是控制器额外发明的“圆形机构”，而是把两条固定杆长约束写成坐标方程。当前正解严格按下面顺序执行，后一步只能使用前一步已经求出的点。
静态 XML 几何 + 实时主动角 qf、qr
        │
        ├──▶ 当前 J、L、P
        │          │
        │          └── J/L 两圆求 M
        │                    │
        │                    └── 由刚体 M–L–K 求 K
        │                              │
        │                              └── K/P 两圆求 N
        │                                        │
        │                                        └── P、N 确定输出刚体姿态，再定位 W
        │
        └──▶ 最终由 I→W 得到 L0、phi0、theta

4.2.1 XML/URDF 到底能直接提供什么

信息静态 XML 能否直接给出实际含义
关节轴、父子关系能决定哪个刚体绕哪里转，以及闭链 equality 把哪些铰点合在一起
vIJ、vIL、vIP、vJM、vML、vMK、vKN、vPN、vPW能点在所属刚体坐标系中的固定局部向量，或由它得到的固定杆长
当前 qf、qr不能由静态文件给出来自 MuJoCo qpos 或真实电机位置反馈
当前 J、L、P 坐标不能直接抄 XML 数值必须把固定局部向量按当前主动角旋转到公共腿平面
当前 M、K、N、W 坐标不能直接抄 XML 数值还要继续满足闭链约束并恢复两个复合刚体的当前姿态

令当前这条腿的共同髋轴 I 为二维原点。XML 给出的是参考构型中的固定向量，运行时用当前主动角得到各点的位置向量：

r→J=R(qf)v→IJref,r→L=R(qr)v→ILref,r→P=R(qr)v→IPref
完整基准也不是依赖上电初态的递推算法。上式中的 vref 是从 XML/CAD 提取并永久保存的机械几何常量，不是车辆每次上电时测量出来的向量。给定任意一组合法的当前模型角 qf、qr，再固定两次圆交的物理装配支路 σM、σN，完整基准可以从头一次性算出 J、L、P、M、K、N、W；推荐简式则只固定 σM 并直接得到 W。两者都不需要上一时刻 W。
r→W=F(qf,qr;σM,σN),(L0,ϕ0)=H(qf,qr;σM,σN)

当前 XML 装配对应固定支路 σM=+1、σN=−1。因此在已验证工作域中，analytic_closed_chain(qf,qr) 是一个无历史状态的确定函数：相同 q 无论先调用、后调用、正序调用还是乱序调用，都会得到相同 W。所谓“与上一周期连续”只是通用圆交器在没有预先固定 σ 时用来防止误选另一个交点的保护策略；它不参与当前点坐标的数值计算。真实机构若不穿过连杆共线的奇异位形，也不可能凭空跳到另一装配支路。

真正必须校准的是角度坐标，而不是正运动学初态。实车反馈必须先换成模型角 qmodel,i=ηipencoder,i+bi，包括前后电机顺序、极性 η 和零偏 b。若这一步错误，给进 H 的 q 就错误；这不等于 H 本身需要上一周期初态。
容易混淆的地方：MuJoCo 运行以后当然可以从 xpos/site_xpos 读出当前点坐标，但那是 MuJoCo 已经替我们完成了树形正运动学和 equality 闭链求解后的结果。要给 STM32 写独立运动学，不能把这些运行时结果当成“URDF 静态文件直接给出的坐标”。当前解析脚本把从 XML 提取出的固定向量保存为 V_IJ…V_PW，每次输入 q 后重新计算当前点。

4.2.2 第一次圆交：已知 J、L，求未知 M

当前 J、L 已经由上式算出。先把两个固定长度定义成明确的标量：

ℓJM:=‖v→JMref‖,ℓLM:=‖v→MLref‖

实体连杆 JM 长度固定，复合刚体 jMK 内 M、L 的距离也固定，所以点 M 的位置向量必须同时满足：

‖r→M−r→J‖=ℓJM,‖r→M−r→L‖=ℓLM

两个圆心 J、L 的当前距离是标量：

ρM:=‖r→L−r→J‖

J、L、M 构成一个三角形，三个边长分别是 ρM、ℓJM、ℓLM。三角形任意一边必须小于另外两边之和，同时大于另外两边之差，因此存在两个非相切交点的条件为：

abs(ℓJM−ℓLM)<ρM<ℓJM+ℓLM

把它完全展开，就是普通三角形的三条要求：

ℓJM+ℓLM>ρM,ℓJM+ρM>ℓLM,ℓLM+ρM>ℓJM
对应到你说的人话：是的，JM+LM>JL；同时还必须有 JM+JL>LM 和 LM+JL>JM。因为当前 JL=ρM，后两条合并后就是 |JM−LM|<JL。差值必须取绝对值，不能只写 LM−JM<JL，否则交换两根杆的长短以后条件会失去对称性。

这里所有带 ℓ、ρ 的量都是长度标量，单位 m；只有带箭头的 r、v 才是二维向量。若取等号，两圆相切、只有一个交点；若越界，两圆没有实交点。

  • “圆心 J、半径 ℓJM”的圆，表示杆 JM 允许 M 出现的全部位置。
  • “圆心 L、半径 ℓLM”的圆，表示固定距离 LM 允许 M 出现的全部位置。
  • 两条要求必须同时满足，因此 M 是两个圆的交点；另一个交点 M′ 对应另一种装配支路。
虚线圆不是车上的零件，也不是轮子。它只是“离某个已知点保持固定距离的所有候选位置”的集合。实际机构中仍然只有杆件和铰点。

4.2.3 M 求出以后才知道 K；再用 K、P 求 N

M、L、K 是同一个平面刚体 jMK 上的三个固定点。M 与 L 不需要和 K 共线；XML 已经保存了三角形 M–L–K 的固定形状。求解分四步：

  1. 第一次圆交给出当前 M；L 已由后侧主动角 qr 给出。
  2. 做向量差 rL−rM，得到当前从 M 指向 L 的向量。
  3. 比较“当前 M→L 方向”与“参考构型 M→L 方向”，差值就是整个刚体相对参考构型转过的角度 α。
  4. 把参考向量 M→K 同样旋转 α，再从当前 M 出发，就得到当前 K。
d→MLcur:=r→L−r→M=ML→current,∠(a→):=atan2(az,as)
α=∠(d→MLcur)−∠(v→MLref),r→K=r→M+R(α)v→MKref
“不能从静态 XML 抄 K”是什么意思：XML 中的 jKN pos 是 K 相对父刚体 jMK 的局部参考向量，不是运行时相对 I 的全局坐标。腿一运动，jMK 会平移并旋转；因此必须先用当前 M 提供平移、用当前 M→L 提供转角 α，再把局部 M→K 旋转和平移出去。只有恰好在 XML 参考构型 α=0 时，静态数值才看起来可以直接使用。

atan2(z分量,s分量) 是“二参数反正切”：末尾的 2 表示函数接收两个参数，不是把括号乘 2。它比 atan(z/s) 多保留两个分量的正负，因此能够区分四个象限。

此时 K、P 都已知，N 再满足：

‖r→N−r→K‖=ℓKN,‖r→N−r→P‖=ℓPN

因此第二次是“圆心 K、半径 ℓKN”与“圆心 P、半径 ℓPN”相交，交点才是 N；带箭头的 rN 才是点 N 的二维位置向量。

4.2.4 P、N 确定输出刚体姿态，再直接定位 W

W 不做第三次圆交。P、N 是同一个输出刚体 jOP 上的两个固定点；它们的当前坐标一旦已知，当前 P→N 方向就确定了这个平面刚体的朝向：

β=atan2(rN,z−rP,z,rN,s−rP,s)−atan2(vPN,z,vPN,s),r→W=r→P+R(β)v→PWref

换成一步一步的人话：

  1. 第二次圆交已经给出 N；P 已由后侧主动角 qr 给出。
  2. P 是输出刚体的位置基准，当前 P→N 是这个刚体的“方向标尺”。
  3. 当前 P→N 与参考 P→N 的角度差就是输出刚体转角 β。
  4. XML 知道轮轴在该刚体上的固定向量 P→W；把它旋转 β，再加到当前 P 上，就得到 W。

N、P、W 不要求共线。我们使用的是同一个刚体的完整参考几何，而不是把一根直线简单延长。

没有“以 N 和 W 为圆心”的步骤。W 此时还是未知点，不能把未知 W 当作已知圆心。理论上也能把 W 写成“以已知 P、N 为圆心”的另一次冗余圆交，但它只会重复已经由刚体姿态确定的结果，当前代码没有这样做。

4.2.5 “J 和 L 是两个不同点”到底是什么意思

严格含义只有一个：它们的当前坐标不能完全重合：

ρM=‖r→L−r→J‖>0

它们不需要水平，不需要具有不同的 s 坐标，也不需要预先放在某条全局轴上。只要 J≠L，平面中就唯一存在一条同时经过 J、L 的直线；在圆交里它叫“连心线”。真实交点还必须满足：

abs(ra−rb)≤ρ≤ra+rb

这里 ra、rb、ρ 全都是长度标量，没有箭头；因此可以做普通的标量加减。第一次闭链代入 ra=ℓJM、rb=ℓLM、ρ=ρM。

  • 严格不等式：通常有两个交点，对应两个装配支路。
  • 等号：两圆相切，只有一个交点。
  • 不满足：当前杆长和两圆心距离无法闭合，该姿态不可达。
  • ρ=0：两圆心重合，连心线方向无法定义，当前公式退化。

4.2.6 最后再看通用圆交公式

先把“点”和“向量”分开。Oa、Ob、X 是机构平面中的几何点；选定同一个坐标原点以后，它们的位置向量分别记为带箭头的 rOa、rOb、rX。所以公式中的加减是二维向量加减，最后得到的 rX=[xs,xz]T 仍是点 X 的二维位置向量。

若机构要求 X 到 Oa 的距离始终为 ra，同时到 Ob 的距离始终为 rb，那么 X 必须同时满足：

‖r→X−r→Oa‖=ra,‖r→X−r→Ob‖=rb

第一式的全部解就是“圆心 Oa、半径 ra”的圆；第二式同理。两条约束同时成立，所以 X 是两个圆的交点。

令：

Δ→ab=r→Ob−r→Oa,ρ=‖Δ→ab‖,e→=Δ→abρ,e→⟂=[−ezes]
e→=esu→s+ezu→z,es=rOb,s−rOa,sρ,ez=rOb,z−rOa,zρ

其中 us、uz 分别是 +s、+z 方向的单位基向量；e_s、e_z 是两个无量纲标量分量，不是两根向量：es 表示 e 沿 +s（当前 XML 的 +base Y）投影多少，ez 表示 e 沿 +z（+base Z、竖直向上）投影多少。它们都不代表车辆的 base X 轴。

具体数值例子：如果从 Oa 到 Ob 沿 +s 走 3 mm、沿 +z 走 4 mm，那么 ρ=5 mm，es=3/5=0.6、ez=4/5=0.8，因而 e=[0.6,0.8]T。e 是一根单位向量；0.6、0.8 只是它在两条坐标轴上的两个标量分量，并满足 es2+ez2=1。

e 是从 Oa 指向 Ob 的单位向量；e⊥ 是把 e 在平面内转 90° 后得到的单位向量。先从 Oa 沿 e 走 a 到垂足 Q，再沿 e⊥ 走 ±h 到交点，所以：

r→X=r→Oa+ae→+σhe→⟂,σ∈{+1,−1}

推导只用到 e 与 e⊥ 互相垂直、长度都为 1。因为 ob=oa+ρe，所以从两个圆心分别看向 X：

r→X−r→Oa=ae→+σhe→⟂⟹‖r→X−r→Oa‖2=a2+h2=ra2
r→X−r→Ob=(a−ρ)e→+σhe→⟂⟹‖r→X−r→Ob‖2=(ρ−a)2+h2=rb2

两式相减后 h² 正好消掉，先得到沿连心线走多远的 a，再回代得到垂直高度 h：

a2−(ρ−a)2=ra2−rb2⟹a=ra2−rb2+ρ22ρ,h=ra2−a2
这不是依赖“J、L 水平”的定理。公式等于在当前斜着的 J→L 方向上临时建立一个局部坐标系：e 沿 J→L，e⊥ 与它垂直。把整张图随意旋转，ρ、a、h 和两个距离约束都不会改变。
atan2 的 2 不是系数。atan2(y,x) 表示“把 y 和 x 两个参数一起交给反正切函数”。例如 atan2(+1,+1)=45°，而 atan2(+1,−1)=135°；若只算 atan(y/x)，第二个例子会错误地退化成 −45°，丢失所在象限。

Ps=vIP,scosqr−vIP,zsinqr,Pz=vIP,ssinqr+vIP,zcosqr

第一次三角形 J–M–L：先求已知边 JL 的长度和方向：

ΔsM=Ls−Js,ΔzM=Lz−Jz,ρM=ΔsM2+ΔzM2
γM=atan2(ΔzM,ΔsM)

J–M–L 三角形的三边是 ℓJM、ℓLM、ρM。在顶点 J 使用余弦定理：

ℓLM2=ℓJM2+ρM2−2ℓJMρMcosηM
ηM=arccos(ℓJM2+ρM2−ℓLM22ℓJMρM)

σM 选择连心线两侧的装配支路，因此 M 的坐标直接是：

Ms=Js+ℓJMcos(γM+σMηM)
Mz=Jz+ℓJMsin(γM+σMηM),σM=+1

由固定刚体三角形 M–L–K 直接定位 K：预先从 XML 计算两个永不改变的标量：

kMK=‖v→MKref‖‖v→MLref‖,δMK=∠(v→MKref)−∠(v→MLref)

因为 M→L 与 M→K 固定在同一个刚体上，当前 M→K 始终等于“当前 M→L 先转固定夹角 δMK，再乘固定比例 kMK”：

[KsKz]=[MsMz]+kMK[cosδMK−sinδMKsinδMKcosδMK][Ls−MsLz−Mz]

这与 α=angle(L−M)−angle(vMLref)、K=M+R(α)vMKref 完全等价；这里只把运行时 α 消掉，改成预先计算的固定比例与固定夹角。

第二次三角形 K–N–P：重复同一个余弦定理：

ΔsN=Ps−Ks,ΔzN=Pz−Kz,ρN=ΔsN2+ΔzN2
γN=atan2(ΔzN,ΔsN)
ηN=arccos(ℓKN2+ρN2−ℓPN22ℓKNρN)
Ns=Ks+ℓKNcos(γN+σNηN)
Nz=Kz+ℓKNsin(γN+σNηN),σN=−1

由固定刚体三角形 P–N–W 直接定位 W：同样预计算：

kPW=‖v→PWref‖‖v→PNref‖,δPW=∠(v→PWref)−∠(v→PNref)
[WsWz]=[PsPz]+kPW[cosδPW−sinδPWsinδPWcosδPW][Ns−PsNz−Pz]

最后 dW=−Wz，再计算 L0 与 φ0。因此整个正解可以严格写成一个无历史输入的复合函数：

(Ws,Wz,L0,ϕ0)=H(qf,qr;σM=+1,σN=−1)
为什么它仍比理想五杆公式长：理想五杆只有一个主要闭合三角形；当前偏置机构包含 J–M–L 与 K–N–P 两次闭合，还包含 M–L–K、P–N–W 两个不共线刚体三角形。因此可以闭式直算，但必然是“两次余弦定理 + 两次固定刚体变换”，不能在不丢失真实几何的情况下压缩成理想五杆那四个短三角函数系数。

4A.2 从电机反馈到轮轴坐标：把两次闭链完全展开

下面的流程只描述正运动学。所谓“闭链 1”是前支路 J→M 与后侧刚体固定点距 L→M 必须在同一个 M 会合；“闭链 2”是连杆 K→N 与输出刚体固定点距 P→N 必须在同一个 N 会合。圆只是这两个固定距离约束的坐标表达。

4A.3 两个“不是圆交”的刚体定位步骤

由 M、L 定位 K

  1. M 给出刚体 jMK 当前放在哪里。
  2. M→L 给出该刚体当前朝哪个方向。
  3. XML 参考三角形已经记住 K 相对 M 在哪里。
  4. 把参考 M→K 与整个刚体一起旋转 α，再从 M 出发即可得到 K。
r→K=r→M+R(α)v→MKref

M、L、K 可以是不共线的三角形；正因为三点属于同一个刚体，固定形状才能被整体旋转和平移。

由 P、N 定位 W

  1. P 给出输出刚体 jOP 当前放在哪里。
  2. P→N 给出该刚体当前朝哪个方向。
  3. XML 参考几何已经记住轮轴 W 相对 P 在哪里。
  4. 把参考 P→W 与刚体一起旋转 β，再从 P 出发即可得到 W。
r→W=r→P+R(β)v→PWref

这里没有以 W 为圆心的圆，也没有第三次圆交；W 是刚体上的固定点，被 P 的位置和 P→N 的朝向唯一带出来。

5. 一次闭链简化后的解析 JH 与 VMC 力矩映射（不生成控制目标）

先说第四、第五节的关系：第 4 节用当前关节角算出轮轴 W 和当前状态 L0、φ0；第 5 节不再重新求另一套几何，而是对第 4 节的同一个 H(q) 求导，得到“关节动一点，状态会怎样变”的 JH，再用 JHT 把上游控制器已经给出的虚拟力换成电机力矩。

5.0 先用人话把这一节要解决的三件事分开

这一节容易看乱，是因为“位置”“位置的变化率”和“力矩”三类量写在了一起。实际上它们依次回答三个不同问题：

问题已知要求使用的关系
① 这条腿现在在哪里？当前模型关节角 qf、qrW、L0、φ0第 4 节正运动学 y=H(q)
② 某台电机再转一点，虚拟腿会怎样变？当前几何与很小的 δqδL0、δφ0本节解析求导 δy=JH(q)δq
③ 已经想要 F0、Tφ，两台电机各出多少力矩？上游 PID/LQR 的虚拟广义力τf、τr虚功关系 τ=JHTf

“解析求导”只表示：从第 4 节的几何等式出发，用代数和链式法则直接写出偏导公式。它不是再做一次控制，也不是让实车真的试着动一下；运行时只需把当前坐标代进公式，就得到当前数值 JH(q)。

贯穿本节的一句话：JH 在运动学上表示“电机转一点，腿长和腿角各变多少”；同一组数在力学上就是当前姿态下的瞬时传动比或等效力臂。先把这个运动关系算准，后面才能依据能量守恒把虚拟力正确分配为两个关节力矩。
第五节不负责产生目标：它不生成 L0des、φ0des，也不决定 F0、Tφ 应该取多少。目标来自遥控器、规划器或姿态目标；F0、Tφ 由上游 PID/LQR 算出。若要把目标 L0、φ0 反算成关节位置目标 q，请看第 6 节。
术语边界：H(q) 是位置运动学；JH=∂H/∂q 是微分运动学；τ=JHTF 是瞬时力传递。它们还不是包含质量、惯性、重力、科氏项和加速度的完整动力学。

5.1 从最普通的“斜率”一步走到 JH

先只看一个输入和一个输出

假设一个电机角度 q 决定一个位置 x=h(q)。导数的定义是：

dhdq(q)=limΔq→0h(q+Δq)−h(q)Δq

它就是“在当前 q 附近，输入每增加一点，输出大约增加多少”。如果当前导数是 0.08 m/rad，那么电机只转很小的 δq=0.01 rad 时：

δx≈0.08×0.01=0.0008 m

这里并不是说 0.08 在整段运动中永远不变；它只是当前姿态切线的斜率。机构换了姿态，就要把当前 q 重新代入导数公式。

现在换成两个输入和两个输出

主动关节和虚拟腿输出分别写成：

q→=[qfqr],y→=H(q→)=[L0(q→)ϕ0(q→)]
完整量和变化量不要混：q、y 是当前完整状态；δq=[δqf,δqr]T 和 δy=[δL0,δφ0]T 才是假想在当前姿态附近发生的很小变化。

这里的 qf、qr 是模型坐标中的前、后主动铰角，不是默认等于电机数组第 0、1 项。H(q) 也不是黑箱：第 4 节已经按 J、L、P→M→W→L0、φ0 的顺序把它完整算出。

因为 L0 同时受 qf、qr 影响，所以必须分别问：

  • 保持 qr 不动，只改变 qf，L0 怎样变？这就是 ∂L0/∂qf；
  • 保持 qf 不动，只改变 qr，L0 怎样变？这就是 ∂L0/∂qr；
  • 对 φ0 再问同样两个问题，于是总共得到四个偏导。

为什么可以把非线性 H(q) 写成一个矩阵乘法

对 H 在当前 q 附近做 Taylor 展开。先把被保留的一阶项写出来：

H(q→+δq→)=H(q→)+∂H∂q→⏟JH(q→)δq→+二阶及更高阶项

所谓“二阶小量”，不是代码里另外求了一个二阶导数再丢掉，而是完整 Taylor 式里本来还包含：

12(H,ffδqf2+2H,frδqfδqr+H,rrδqr2)+⋯

当 δq 很小时，δq² 比 δq 小得多，所以只保留一阶项。再用“新值减旧值”定义 δy：

δy→:=H(q→+δq→)−H(q→)

于是得到当前姿态附近的局部线性关系：

δy→≈JH(q→)δq→
[δL0δϕ0]=[∂L0∂qf∂L0∂qr∂ϕ0∂qf∂ϕ0∂qr][δqfδqr]

把矩阵乘法按行展开，就更直白：

δL0≈∂L0∂qfδqf+∂L0∂qrδqr
δϕ0≈∂ϕ0∂qfδqf+∂ϕ0∂qrδqr
元素实际含义单位
J11=∂L0/∂qf只让前电机增加 1 rad，腿长瞬时改变多少m/rad
J12=∂L0/∂qr只让后电机增加 1 rad，腿长瞬时改变多少m/rad
J21=∂φ0/∂qf只让前电机增加 1 rad，虚拟腿极角瞬时改变多少rad/rad
J22=∂φ0/∂qr只让后电机增加 1 rad，虚拟腿极角瞬时改变多少rad/rad

因此，在当前姿态附近可以找到一个 2×2 数值矩阵 JH(q)，把输入微小变化映射成输出微小变化。公式形式固定，但代入不同 q 后，四个元素的数值会变。控制周期下一次到来时，用新的 q 再算一次即可；并不是拿上电时的一组常数覆盖整段运动。

把同一关系除以很小的时间间隔并取极限，就得到瞬时速度关系：

[L˙0ϕ˙0]=JH(q→)[q˙fq˙r]
解析 JH 与中心差分的区别：中心差分要把 q±ε 多次送入 H 再用输出差除以输入差；解析求导则把下面的链式法则提前化成公式，运行时一次代入当前点坐标就得到同一个局部斜率。中心差分仍可留在 PC 端验算，但不是 STM32 的控制算法。

5.2 从轮轴二维坐标继续推到 L0、φ0 的导数

第 4 节已经给出轮轴点 W。以本侧髋轴 I 为原点，把 I→W 投影到“+s=+base Y”和“+d=−base Z（车体向下）”两条轴：

Ir→W(s,d)(q→)=[sW(q→)dW(q→)],sW=YW−YI,dW=−(ZW−ZI)
sW、dW 都是位置，不是速度。下标 W 表示“轮轴点 W”；二者单位都是 m。只有带时间点的 ṡW、ḋW 才是 m/s。这里字母 d 来自英文 down，不是微分符号。
L0=sW2+dW2,ϕ0=atan2(dW,sW)

因此 [sW,dW]T 是同一根 I→W 向量在两条垂直坐标轴上的两个位置分量；L0 是这根向量的长度，φ0 是它从 +s 轴转向 +d 轴的方向角。竖直向下时 sW=0、dW>0，所以 φ0=90°。

第一步：把腿长公式逐项微分

先平方，避免直接对根号求导：

L02=sW2+dW2

令轮轴位置发生微小变化 δsW、δdW，等式两边取一阶变化：

2L0δL0=2sWδsW+2dWδdW

两边除以 2L0，得到：

δL0=sWL0δsW+dWL0δdW

它的直观意义是：轮轴的小位移 [δsW,δdW]T 在虚拟腿径向上的投影才改变腿长；与虚拟腿垂直的那部分不改变一阶腿长。

第二步：把 atan2 的角度公式逐项微分

在 sW≠0 的局部可先写成 tanφ0=dW/sW。对两边取一阶变化：

sec2ϕ0δϕ0=δ(dWsW)=sWδdW−dWδsWsW2

又因为：

sec2ϕ0=1+tan2ϕ0=1+dW2sW2=sW2+dW2sW2=L02sW2

代回并约掉 s²：

δϕ0=−dWL02δsW+sWL02δdW

上面借 tanφ0 展示代数步骤；实际程序使用二参数反正切 atan2(dW,sW)，所以 sW=0 附近仍使用同一个微分结果，只要 L0≠0 且角度差做 wrap。函数名中的 2 不是倍数。

写成矩阵：

[δL0δϕ0]=[sW/L0dW/L0−dW/L02sW/L02]⏟Cpolar=∂(L0,ϕ0)/∂(sW,dW)[δsWδdW]
本报告从这里开始不再把 JP 当作运行时必经接口。下一节直接对真实闭链的每个点做解析求导，最终一次性输出 JH。数学上当然仍然存在“轮轴对关节角怎样变化”的信息，但它被包含在点 W 的内部导数 DW 中，不需要单独用中心差分求 JP，也不需要保存一个 JP 矩阵。

上面的 Cpolar 只负责最后一步：把已经解析得到的轮轴微小位移换成腿长和腿角微小变化。下面从主动点 J、L、P 开始，逐项求出这一轮轴导数。

5.3 第一段解析求导：主动点 J、L、P 为什么这样求

本节的任务很单纯：先求直接固定在两根主动刚体上的点怎样随电机角移动。这里没有 ε，也没有重复计算扰动姿态；推荐导数链是 J、L、P→被动闭链点 M→轮轴 W。

先规定导数矩阵每一行、每一列在说什么

任意二维点 X 的当前位置写成：

r→X=[XsXz]

它有两个坐标，每个坐标又可能受两台电机影响，所以一共有四个偏导：

Xs,f:=∂Xs∂qf,Xs,r:=∂Xs∂qr,Xz,f:=∂Xz∂qf,Xz,r:=∂Xz∂qr
DX:=∂r→X∂(qf,qr)=[Xs,fXs,rXz,fXz,r]
  • 第一列：只让前关节 qf 增大一点时，点 X 在 s、z 两方向怎样移动；
  • 第二列：只让后关节 qr 增大一点时，同一个点怎样移动；
  • 这两列都不是实际位移，而是“每 1 rad 输入对应多少米输出”的当前斜率。

一个绕 I 转动的点，导数为什么等于当前向量转 90°

若参考向量为 v，随关节角 q 一起旋转，则：

R(q)=[cosq−sinqsinqcosq],r→(q)=R(q)v→

把两个坐标直接写开：

rs=vscosq−vzsinq,rz=vssinq+vzcosq

逐项对 q 求导：

∂rs∂q=−vssinq−vzcosq=−rz
∂rz∂q=vscosq−vzsinq=rs

因此：

∂r→∂q=[−rzrs]=[0−110]⏟E：逆时针转 90∘r→

物理上也很好理解：刚性杆绕 I 旋转时，端点的瞬时运动方向一定垂直于当前杆；长度越长，同样的角度变化产生的端点位移越大。

主动前点 J：只由 qf 直接带动

Js=vIJ,scosqf−vIJ,zsinqf,Jz=vIJ,ssinqf+vIJ,zcosqf

套用刚才的结果：

Js,f=−Jz,Jz,f=Js

J 不固定在后主动刚体上，所以保持 qf 不变而单独改变 qr 时，J 不会直接动：

Js,r=0,Jz,r=0
DJ=[−Jz0Js0]

主动后点 L、P：只由 qr 直接带动

Ls=vIL,scosqr−vIL,zsinqr,Lz=vIL,ssinqr+vIL,zcosqr

CAD 推荐模型规定 I、L、P 共线，且 |IP|=ka|IL|，所以不必为 P 再保留一套独立方向：

r→P=kar→L,Ps=kaLs,Pz=kaLz

先求 L 的导数，再把同一比例传给 P：

Ls,f=Lz,f=0,Ls,r=−Lz,Lz,r=Ls
DL=[0−Lz0Ls]
DP=kaDL=[0−Pz0Ps]
这里出现 0 不代表这台电机永远不影响最终轮轴。它只表示 J、L、P 这些“主动刚体上的直接点”分别由哪一个主动角直接带动。闭链点 M 同时受 J 和 L 约束，算到 M、W 后，两列通常都会非零。

5.4 第二段解析求导：闭链点 M 的导数怎样从两条杆长约束中解出来

为什么 M 不能像 J、L 那样直接写成“当前向量转 90°”

J 固定在前主动刚体上，L 固定在后主动刚体上；M 却是两根被动杆 JM、LM 的共同铰点。它没有自己的电机角，必须在 J、L 移动后同时满足：

‖r→M−r→J‖=ℓJM,‖r→M−r→L‖=ℓLM

第 4 节已经用余弦定理选定当前物理装配支路，并算出了 M 的坐标。本节不是再求一次 M，而是问：当 qf 或 qr 增加极小量时，为了让两根杆仍保持定长，M 必须往哪个方向移动？

第一条定长约束：把每一个链式法则步骤写开

(Ms−Js)2+(Mz−Jz)2=ℓJM2

选一个输入角 qj；j=f 时表示只考察前关节，j=r 时表示只考察后关节。先看第一项：

∂∂qj(Ms−Js)2=2(Ms−Js)(∂Ms∂qj−∂Js∂qj)

z 项完全相同。右边的 ℓJM 是固定杆长，不随 q 改变，所以 ∂ℓJM2/∂qj=0。于是：

2(Ms−Js)(Ms,j−Js,j)+2(Mz−Jz)(Mz,j−Jz,j)=0

为了缩短后面的式子，定义从 J、L 指向 M 的当前向量：

us:=Ms−Js,uz:=Mz−Jz,vs:=Ms−Ls,vz:=Mz−Lz

约掉 2，并把已知的 J 导数移到右边：

usMs,j+uzMz,j=usJs,j+uzJz,j=:b1j

这句话的人话版本是：M 和 J 在 JM 杆方向上的相对速度必须为零，否则杆长就会在一阶上发生变化。

第二条定长约束给出第二个独立方程

(Ms−Ls)2+(Mz−Lz)2=ℓLM2

完全重复刚才的链式法则：

vsMs,j+vzMz,j=vsLs,j+vzLz,j=:b2j

现在未知数只有两个：Ms,j 和 Mz,j。两条定长约束恰好给出两个一次方程：

{usMs,j+uzMz,j=b1jvsMs,j+vzMz,j=b2j
[usuzvsvz][Ms,jMz,j]=[b1jb2j]

不用背 Cramer 公式：手工消元一次就能看见答案

为消掉 Mz,j，第一式乘 vz，第二式乘 uz，然后前式减后式：

(usvz−uzvs)Ms,j=vzb1j−uzb2j

定义：

ΔM:=usvz−uzvs

只要 ΔM≠0：

Ms,j=vzb1j−uzb2jΔM

同理，为消掉 Ms,j，第一式乘 vs，第二式乘 us 后相减，得到：

Mz,j=−vsb1j+usb2jΔM

把两式写成逆矩阵或 Cramer 法则只是一种压缩记法；真正做的事情就是上面的两次消元。

ΔM 的机械意义：它是向量 J→M 与 L→M 的二维叉积。若 ΔM=0，两根杆在这一刻共线，两条约束给出的瞬时方向信息重复，二维的 M 导数无法唯一确定；这就是闭链展开或折叠附近的机械奇异。

把 qf 这一列完全代入

L 不受 qf 直接驱动，因此 Ls,f=Lz,f=0：

b1f=usJs,f+uzJz,f=−usJz+uzJs,b2f=0
Ms,f=vz(−usJz+uzJs)ΔM
Mz,f=−vs(−usJz+uzJs)ΔM

把 qr 这一列完全代入

J 不受 qr 直接驱动，因此 Js,r=Jz,r=0：

b1r=0,b2r=vsLs,r+vzLz,r=−vsLz+vzLs
Ms,r=−uz(−vsLz+vzLs)ΔM
Mz,r=us(−vsLz+vzLs)ΔM
为什么没有对余弦定理中的根号和 atan2 直接求导：无论第 4 节用哪种显式写法得到 M，它都必须满足上面两条定长等式。直接对这两个等式求导，会得到当前已选装配支路的同一个精确一阶导数。它叫“隐式解析求导”：隐式是因为 M 藏在约束里，解析是因为结果仍由明确代数公式算出，并不是中心差分近似，也不依赖上一周期。

5.5 推荐解析导数：从 M、L、P 一步得到 W

第 4 节已经得到 CAD 设计模型的固定几何关系：

r→P=kar→L,r→W=r→P+kb(r→M−r→L)

先把 W 的两个坐标写开，避免矩阵公式突然出现：

Ws=kbMs+(ka−kb)Ls,Wz=kbMz+(ka−kb)Lz

ka、kb 是由杆长决定的常数，不随关节角变化。对任意 qj 逐项求导：

Ws,j=kbMs,j+(ka−kb)Ls,j
Wz,j=kbMz,j+(ka−kb)Lz,j

把 j=f、r 两列重新合在一起，才得到紧凑矩阵形式：

DP=kaDL
DW=DP+kb(DM−DL)=kbDM+(ka−kb)DL

这一步把“关节微动如何传到轮轴”算完了。DM 已由 5.4 的闭链约束得到，DL、DP 已由 5.3 得到，因此推荐 CAD 简化链不需要第二个隐式方程组。

把 qf 这一列完全展开

L、P 都不直接受 qf 驱动，所以 Ls,f=Lz,f=Ps,f=Pz,f=0：

Ws,f=kbMs,f
Wz,f=kbMz,f

把 qr 这一列完全展开

由 Ls,r=−Lz、Lz,r=Ls、Ps,r=−Pz、Pz,r=Ps：

Ws,r=kbMs,r−(ka−kb)Lz
Wz,r=kbMz,r+(ka−kb)Ls

这里使用 Ls,r=−Lz、Lz,r=Ls；ka=2.217，kb=2.243。

到这里还没有真正输出力矩。这里完成的是力矩分配所需的轮轴微分几何。下一节还要把 W 的 s、z 导数转换成 L0、φ0 的导数，形成 JH；5.7–5.8 才会用虚功得到电机力矩。不能只把旧电机力矩乘一个 kb。
5A. 完整 K–N 基准模型的解析导数（仅作离线交叉验证）

5A.1 刚体 M–L–K：用固定比例和固定夹角直接传播到 K

参考构型中的 M→L 与 M→K 都固定在同一刚体上。预计算：

kMK:=‖v→MKref‖‖v→MLref‖,δMK:=∠(v→MKref)−∠(v→MLref)

为什么这是严格关系：若刚体当前整体旋转 α，则：

r→L−r→M=R(α)v→MLref
r→K−r→M=R(α)v→MKref=R(α)TMKv→MLref

二维旋转矩阵彼此可交换，所以 R(α)TMK=TMKR(α)，于是：

r→K=r→M+TMK(r→L−r→M)

把坐标分量完全展开：

Ks=Ms+t11(Ls−Ms)+t12(Lz−Mz)
Kz=Mz+t21(Ls−Ms)+t22(Lz−Mz)

TMK 是常数矩阵，所以对任意 qj 直接求导：

Ks,j=Ms,j+t11(Ls,j−Ms,j)+t12(Lz,j−Mz,j)
Kz,j=Mz,j+t21(Ls,j−Ms,j)+t22(Lz,j−Mz,j)

分别令 j=f、r，并代入上一节的 M 偏导和 5.3 的 L 偏导，就得到 Ks,f、Kz,f、Ks,r、Kz,r。这与对 α 和 R(α)vMK 求导完全等价，但不需要运行时再对 α 做一次角度求导。

5A.2 第二次闭链：由 K、P 完整解出 N 的四个偏导

(Ns−Ks)2+(Nz−Kz)2=ℓKN2
(Ns−Ps)2+(Nz−Pz)2=ℓPN2

定义：

逐项求导并移项：

asNs,j+azNz,j=asKs,j+azKz,j=:c1j
csNs,j+czNz,j=csPs,j+czPz,j=:c2j
[asazcscz][Ns,jNz,j]=[c1jc2j]

定义第二次闭链行列式：

ΔN:=ascz−azcs

逆矩阵和显式解为：

[asazcscz]−1=1ΔN[cz−az−csas]
Ns,j=czc1j−azc2jΔN,Nz,j=−csc1j+asc2jΔN

qf 列

P 不受 qf 直接驱动：

c1f=asKs,f+azKz,f,c2f=0
Ns,f=cz(asKs,f+azKz,f)ΔN
Nz,f=−cs(asKs,f+azKz,f)ΔN

qr 列

c2r=csPs,r+czPz,r=−csPz+czPs

预先从参考刚体几何计算：

kPW:=‖v→PWref‖‖v→PNref‖,δPW:=∠(v→PWref)−∠(v→PNref)
TPW:=kPWR(δPW)=[r11r12r21r22]

与 M–L–K 的证明完全相同：

r→W=r→P+TPW(r→N−r→P)

坐标与导数逐项展开：

Ws=Ps+r11(Ns−Ps)+r12(Nz−Pz)
Wz=Pz+r21(Ns−Ps)+r22(Nz−Pz)
Ws,j=Ps,j+r11(Ns,j−Ps,j)+r12(Nz,j−Pz,j)
Wz,j=Pz,j+r21(Ns,j−Ps,j)+r22(Nz,j−Pz,j)

令 j=f、r，即得到轮轴的四个解析偏导 Ws,f、Wz,f、Ws,r、Wz,r。程序内部可以用 DW 保存这四个中间数，但不需要建立公开的 JP 接口。

5.6 最后一段解析求导：从轮轴 W 的导数得到最终 JH

5.5 得到的是轮轴在几何 (s,z) 坐标中的导数。控制器把“向下”定义为 d 正方向，因此先做一次明确的符号转换：

sW=Ws,dW=−Wz

坐标取负以后，对关节角的导数也必须取负：

∂sW∂qj=Ws,j,∂dW∂qj=−Wz,j
DW(s,d)=[Ws,fWs,r−Wz,f−Wz,r]

5.2 已经求出从轮轴二维坐标到极坐标的变化关系：

[δL0δϕ0]=[sW/L0dW/L0−dW/L02sW/L02]⏟Cpolar[δsWδdW]

而轮轴坐标的小变化由 5.5 的导数给出：

[δsWδdW]=DW(s,d)[δqfδqr]

前式代入后式：

JH=CpolarDW(s,d)

这就是完整链式法则：关节角 → 轮轴二维位置 → 腿长和腿角。以第一列为例，矩阵乘法逐项展开：

JH,11=sWL0Ws,f+dWL0(−Wz,f)=WsWs,f+WzWz,fL0
JH,21=−dWL02Ws,f+sWL02(−Wz,f)=WzWs,f−WsWz,fL02

第二列只需把下标 f 换成 r。因此，对任意 qj：

∂L0∂qj=WsWs,j+WzWz,jL0
∂ϕ0∂qj=WzWs,j−WsWz,jL02

分别代入 j=f 和 j=r，得到最终四个明确元素：

JH,11=WsWs,f+WzWz,fL0,JH,12=WsWs,r+WzWz,rL0
JH,21=WzWs,f−WsWz,fL02,JH,22=WzWs,r−WsWz,rL02
JH=[JH,11JH,12JH,21JH,22]=∂(L0,ϕ0)∂(qf,qr)
到这里解析运动学部分才真正闭合。第 4 节给当前位置；5.3–5.5 给轮轴对两关节的四个偏导；5.6 把它们变成 JH。每条腿每周期只需一次正解、一个 2×2 闭链导数解和常数比例传播；没有中心差分、没有 ε、没有五次重复 H(q)，也没有 Newton 闭链迭代。下面才进入“怎样用 JH 分配力矩”。

解析公式的分母为什么正好给出机械奇异条件

  • ΔM=0 表示向量 M−J 与 M−L 共线，即 J、M、L 共线；第一次两圆相切或相关杆完全展开/折叠。
  • 完整离线基准中的 ΔN=0 仍表示 K、N、P 共线，但推荐实时简化链不需要计算 ΔN。
  • L0=0 时虚拟腿方向 φ0 本身无定义。
  • 即使上述三项不为零，det(JH)=0 仍表示两个主动关节不能在当前姿态独立产生两个虚拟输出方向。

当前验证域内，推荐实时链实际使用的 ΔM 范围为 [+1.011e-02, +1.322e-02] m²，未接近 0 或变号。完整基准的 ΔN 范围为 [-7.527e-03, -4.325e-03] m²，只用于确认第二级平行四边形没有在验证域内跳到另一装配支路。

中心差分现在只承担离线交叉验证，不属于控制算法

为了独立检查推荐解析式有没有漏负号，PC 测试仍可对同一个 H(q) 做很小的中心差分，再与解析 JH 比较。它相当于“用另一把尺子验算”，不会被移植进 STM32：

JH,:,1FD=H(qf+ε,qr)−H(qf−ε,qr)2ε,JH,:,2FD=H(qf,qr+ε)−H(qf,qr−ε)2ε

在当前二维验证网格上，解析公式与解析正解中心差分的四元素最大绝对差为 1.022e-09；与独立 XML 变换树/被动角闭链求解再做中心差分的最大差为 8.410e-09。因此中心差分已经从“运行算法”降级为“离线单元测试”。

5.7 从零开始理解虚位移、虚功，以及为什么一定出现 JHᵀ

5.7.1 “虚位移”不是让实车真的执行一次动作

在当前这一帧、当前姿态 q 不变的前提下，假想机构发生一个无限小并且满足所有杆长约束的变化，这个假想变化就叫虚位移：

δq→=[δqfδqr],δy→=[δL0δϕ0]
  • 它不是持续了 δt 秒的真实运动命令，也不是让电机先试转再测量；
  • 它只是用来比较“若关节允许这样微动，输入侧与输出侧怎样描述同一份瞬时机械作用”；
  • 它必须服从闭链约束，所以仍有 δy=JHδq。

5.7.2 先用一根杠杆理解“Jacobian 就是当前等效力臂”

设一台电机带动长度为 r 的刚杆，电机发生很小转角 δq，杆端沿切线移动：

δs=rδq

电机力矩 τ 在转角 δq 上做的微小功为 τδq；杆端切向力 F 在位移 δs 上做的微小功为 Fδs。把同一理想传动两侧的瞬时功写成两种坐标：

τδq=Fδs=Frδq

对任意非零小 δq，都有：

τ=rF

这里 r=∂s/∂q 就是一维 Jacobian。杆越长，同样的关节转角带来越大的末端位移；反过来，要在末端产生同样的力，也需要更大的关节力矩。这就是“运动传动比”和“等效力臂”其实是同一组数的原因。

5.7.3 为什么虚拟腿一侧同时出现 F0 和 Tφ

虚拟腿有两个独立输出坐标：

  • L0：沿虚拟腿轴向伸长/缩短，和它配对的广义力是 F0，单位 N；
  • φ0：整根虚拟腿绕髋轴摆动，和它配对的广义力矩是 Tφ，单位 N·m。

“配对”或“共轭”的意思就是力乘自己的位移坐标后得到功。因此规定正方向：

f→=[F0Tϕ],F0>0 沿 L0 增大方向做正功,Tϕ>0 沿 ϕ0 增大方向做正功

虚拟腿侧的总虚功是两个独立通道之和：

δWvirtual=F0δL0+Tϕδϕ0

这不是把同一个力重复算两次。F0 管径向支撑/腿长，Tφ 管绕髋摆动/腿姿态；任一项都可以单独为零。若把轮轴处的普通二维力分解为径向和切向，径向分量对应 F0，切向分量乘 L0 后就对应 Tφ。

它也不是 9025 轮毂自转力矩。Tφ 与整根虚拟腿角 φ0 配对；轮毂力矩 Twheel 与轮子自转角 ψwheel 配对，另有 δWwheel=Twheelδψwheel。两条控制链不能混在一起。

5.7.4 不先写矩阵：把两台电机的虚功逐项展开

先把 5.1 的运动关系写成四个系数：

δL0=J11δqf+J12δqr
δϕ0=J21δqf+J22δqr

代入虚拟腿侧虚功：

δWvirtual=F0(J11δqf+J12δqr)+Tϕ(J21δqf+J22δqr)

把 δqf 和 δqr 的系数分别收集：

δWvirtual=(J11F0+J21Tϕ)δqf+(J12F0+J22Tϕ)δqr

同一份作用在关节坐标中写成：

δWjoint=τfδqf+τrδqr

为什么可以直接比较系数？因为虚位移可以分别选择：

  • δq=[ε,0]T：只考察前关节，于是 τf=J11F0+J21Tφ；
  • δq=[0,ε]T：只考察后关节，于是 τr=J12F0+J22Tφ。
τf=J11F0+J21Tϕ,τr=J12F0+J22Tϕ

所以 VMC 不是把一个“总力矩”平均分给两台电机。每台电机的力矩都由两部分相加：它对腿长的瞬时影响 × F0，再加上它对腿角的瞬时影响 × Tφ。

5.7.5 最后再压缩成矩阵，转置就不再神秘

JH=[J11J12J21J22],JHT=[J11J21J12J22]
τ→=JHTf→=JHT[F0Tϕ]

运动关系中，JH 的每一列记录一台电机对所有输出的影响。求某台电机力矩时，要取这一整列与 [F0,Tφ]T 做内积；把“列”排成输出力矩向量的“行”，写出来正好就是 JHT。

矩阵版的同一证明是：

τ→Tδq→=f→Tδy→=f→TJHδq→=(JHTf→)Tδq→

转置不是经验公式，也不只是为了凑矩阵尺寸。它是要求同一瞬时虚功用关节坐标和虚拟腿坐标描述时完全一致，自然得到的对偶映射。

5.7.6 一个纯示意数值：直接检查两边虚功相等

下面只为解释公式，不代表当前车辆的真实 JH：

JH=[0.08−0.060.70.8],f→=[40 N3 Nm]

于是：

τf=0.08×40+0.7×3=5.3 Nm
τr=−0.06×40+0.8×3=0 Nm

再任选一个合法的小虚位移 δq=[0.001,−0.002]T rad：

δy→=JHδq→=[0.0002 m−0.0009 rad]
δWvirtual=40×0.0002+3×(−0.0009)=0.0053 J
δWjoint=5.3×0.001+0×(−0.002)=0.0053 J

两边完全相等。这是检查转置、列顺序和角度正负号是否正确的直接方法。

5.8 从数学力矩公式落到当前 VMC 接口

5.8.1 先只看新的精确模型接口

JH=[∂L0/∂qf∂L0/∂qr∂ϕ0/∂qf∂ϕ0/∂qr]
τqf=∂L0∂qfF0+∂ϕ0∂qfTϕ
τqr=∂L0∂qrF0+∂ϕ0∂qrTϕ
单位检查：(∂L0/∂q)[m/rad]×F0[N] 得 N·m；(∂φ0/∂q)[rad/rad]×Tφ[N·m] 仍得 N·m。两项单位相同，所以可以相加为关节力矩。

5.8.2 旧理想五杆代码的 j11…j22 只是把 JT 直接存进字段

当前 VMC_Calc.c 字段旧理想五杆中的真实含义进入哪一个旧控制坐标力矩
vmc->j11∂L0/∂φ1τφ1 的 F0 系数
vmc->j12∂φ0/∂φ1τφ1 的 Tφ 系数
vmc->j21∂L0/∂φ4τφ4 的 F0 系数
vmc->j22∂φ0/∂φ4τφ4 的 Tφ 系数

所以旧代码更准确的名字应当是：

torque_phi1 = j11 * F0 + j12 * Tp;   // torque_set[0]
torque_phi4 = j21 * F0 + j22 * Tp;   // torque_set[1]

不能直接把第一行叫 torque_front：在现有左腿旧坐标里，φ1 与后侧支路相连，φ4 与前侧支路相连，发送层还会做交换和取负。

若把旧理想五杆运动雅可比按“输出行、关节列”排布：

Jctrl=∂(L0,ϕ0)∂(ϕ1,ϕ4)=[j11j21j12j22]

那么代码字段实际排成：

Ccode=[j11j12j21j22]=JctrlT

当前左腿旧路径还包含：

q_front = jIJ / motor0  ↔  φ4 ≈ −q_front + offset4
q_rear  = jIO / motor1  ↔  φ1 ≈ −q_rear  + offset1

旧控制坐标力矩 [τφ1, τφ4]
        ↓ 交换并取负
raw-q 广义力矩 [τq_front, τq_rear] = [−τφ4, −τφ1]

因此，如果新的精确 JH 已经直接对 [qfront,qrear] 求导，并输出 [τqf,τqr]，就不能再无条件套用旧交换与负号，否则会把同一坐标变换做两遍。

5.8.3 Tφ 与以 θ 为坐标的力矩为什么相差一个负号

本报告的第二个输出坐标是 φ0。若另一个控制模型定义：

θ=π2−Pitchside−ϕ0

固定 Pitchside、只看腿机构的小变化：

δθ=−δϕ0

若 Tθ 与 θ 正方向共轭，同一份虚功必须满足：

Tθδθ=Tϕδϕ0

所以：

Tϕ=−Tθ

当前工程中的 Tp 已经怎样处理了这个负号

必须把 MATLAB 动力学里的输入和送进 VMC 的变量分开命名：

Tp,dyn 与动力学坐标 (θ,Pitchside)配套,Tϕ 与 VMC 坐标 ϕ0配套

由同一份虚功可得 Tp,dyn=−Tφ。MATLAB 的 lqr() 又采用 u=−Kx，所以：

Tp,dyn=−KTpx,qquadTϕ=−Tp,dyn=+KTpx

当前固件 CalcLQR() 计算 +Kx，再把该值直接送入 VMC_calc_2() 的 Tp，因此当前这个 Tp 在 VMC 接口处就是 Tφ；不是漏了负号，而是“坐标反号”和 LQR 标准反馈中的负号已经抵消。

以后更换精确 JH 时不要再凭变量名补一个负号。保持接口明确为 Tφ，并继续检查模型前/后顺序、电机编码器极性和左右腿重排。源码能证明代数链自洽，但 DM8009 的物理正力矩方向仍需低力矩台架测试确认。
作用力定义也要写清：上式把 [F0,Tφ] 定义为执行器希望沿输出正方向施加的虚拟广义力。如果某个传感器量定义的是环境对机器人的反作用力，接口中可能还要整体取反；那是作用对象的约定，不是 JT 本身改变。

5.9 从模型前/后关节力矩落到真实电机力矩

到 5.8 为止得到的是模型顺序 [front,rear] 下的广义力矩。真实程序中的电机数组可能不是这个顺序，而且编码器正方向也可能与模型 q 正方向相反。因此要分三步看：

  1. Π 只负责把真实电机数组重排成 [front,rear]；
  2. S=diag(ηf,ηr) 只负责把两台编码器的正方向变成模型正方向；
  3. b 只负责把编码器零点平移到模型零点。
p→ordered=Πp→motor,q→=Sp→ordered+b→

合并以后才是：

q→=SΠp→motor+b→
量作用是否影响位置是否影响雅可比/力矩方向
Π把电机数组顺序重排成 [front,rear]是是；输出力矩必须做逆重排 Πᵀ
S=diag(ηf,ηr)把每台电机的正方向换成 XML raw-q 正方向；ηf、ηr∈{+1,−1}是是；对应力矩也要乘同一方向变换 Sᵀ
b编码器零点到模型零点的固定偏移是；决定送入 H 的当前 q对微分为 0，不额外产生力矩负号

为什么 b 不直接产生一个力矩负号？比较同一姿态前后的微小变化即可：

δq→:=q→(p→+δp→)−q→(p→)
δq→=[SΠ(p→+δp→)+b→]−[SΠp→+b→]

两项 b 互相抵消：

δq→=SΠδp→motor

代入 dy=JHdq，得到相对于真实电机反馈顺序的雅可比：

δy→=JHSΠ⏟Jmotorδp→motor

模型关节侧虚功为 τqTδq。代入上式：

τ→qTδq→=τ→qTSΠδp→motor=(ΠTSTτ→q)Tδp→motor

所以真实电机数组中的力矩必须使用逆重排和同一极性变换：

τ→motor=JmotorTf→=ΠTSTJHT[F0Tϕ]

这条式子把“力矩怎样分给两台电机”完整闭合了：JHT 先得到模型前/后关节力矩，ST 修正电机正方向，ΠT 再放回真实电机数组位置。零偏 b 虽然不直接出现在最后一行，但它若标错，会让 JH 在错误姿态上计算，仍会间接造成力矩大小错误。

当前旧理想五杆发送链的源码核对结果：左腿为 motor0=−τφ4、motor1=−τφ1；右腿为 motor2=−τφ1、motor3=−τφ4。这些交换和负号来自旧 φ1/φ4 坐标与电机数组的关系。新的精确接口若直接输出 raw-q 的 [τqf,τqr]，应重新按 Π、S 生成电机力矩，不能照抄旧式。
当前工程必须特别处理右腿顺序：精确接口的自然列固定为 [front,rear]。当前 XML 右腿对应 [jAB,jAG]，而现有右腿电机数组到达顺序是 [motor2=jAG 后，motor3=jAB 前]，因此右腿 Π 需要交换两列，力矩输出也必须逆交换。左腿 XML 自然顺序 [jIJ,jIO] 对应 [motor0 前，motor1 后]。这里说的是 XML raw-q 接口；旧理想 φ1/φ4 路径还叠加了交换与负号，不能混成一套。
VMC 算出的 τ 目前只是 DM8009 MIT 报文中的前馈力矩 tff。实际电机内部还会叠加 Kp(pdes−p) 和 Kd(vdes−v) 等位置/速度反馈作用。因此“JT 分配出的力矩”与驱动器最终瞬时总力矩不能直接画等号；调试时必须同时记录 pdes、Kp、Kd、tff 和电机反馈。

5.10 当前理想五杆的四个三角函数系数怎样推出来

这一小节解释当前 VMC_calc_2() 的 j11…j22 来源；它属于 PDF 的理想五连杆，不是偏置 XML 的精确 JH。令：

e→i=[cosϕisinϕi],t→i=[−sinϕicosϕi]

ei 沿第 i 根杆，ti 是该杆逆时针转动时端点的瞬时切向方向。理想五杆轮轴 C 同时满足：

r→C=r→B+l2e→2=r→D+l3e→3

先只让主动角 φ1 变化、固定 φ4。B 点速度是 l1t1φ̇1，D 点速度为 0。杆 BC、DC 长度不能变化，因此 C 相对 B、D 的速度在相应杆方向上的投影必须为零：

e→2T(v→C−l1t→1ϕ˙1)=0,e→3Tv→C=0

第二式说明 vC 必须沿 t3，把它代入第一式并解比例：

∂r→C∂ϕ1=l1sin(ϕ1−ϕ2)sin(ϕ3−ϕ2)t→3

虚拟腿的径向单位向量为 e0，切向单位向量为 t0。轮轴速度投影到径向得到腿长变化，投影到切向再除以 L0 得到角度变化：

∂L0∂ϕ1=e→0T∂r→C∂ϕ1,∂ϕ0∂ϕ1=1L0t→0T∂r→C∂ϕ1

利用 e0Tt3=sin(φ0−φ3)、t0Tt3=cos(φ0−φ3)，就得到当前代码前两项：

j11=l1sin(ϕ0−ϕ3)sin(ϕ1−ϕ2)sin(ϕ3−ϕ2),j12=l1cos(ϕ0−ϕ3)sin(ϕ1−ϕ2)L0sin(ϕ3−ϕ2)

再只让 φ4 变化、固定 φ1，同样用两根被动杆的定长速度约束：

∂r→C∂ϕ4=l4sin(ϕ3−ϕ4)sin(ϕ3−ϕ2)t→2

投影到 e0、t0 后：

j21=l4sin(ϕ0−ϕ2)sin(ϕ3−ϕ4)sin(ϕ3−ϕ2),j22=l4cos(ϕ0−ϕ2)sin(ϕ3−ϕ4)L0sin(ϕ3−ϕ2)
精确偏置机构改变的就是这里：虚功和“径向/切向投影”的思想不变，但不能继续使用上面针对理想 B–C–D 五杆推出来的四个三角函数系数；应改用第 4 节真实闭链 H(q) 的 JH。

5.12 怎样证明 JH 和力矩分配没有算错

  1. CAD 关系检查：逐点验证 P=kaL、W=P+kb(M−L)，并把结果与最终对齐后的 CAD/XML 模型比较。当前 XML 尚保留约 0.271 mm 的 I–L–P 导出偏差，因此不能再拿旧的微米级指标冒充 CAD 模型误差。
  2. 有限位移检查：任选很小 δq，比较 H(q+δq)−H(q) 与 JHδq；误差应随 ‖δq‖² 缩小。
  3. MuJoCo 几何检查：分别扰动 qf、qr，调用 mj_forward，从真实轮轴 site/body 重新计算 L0、φ0；所得斜率应与 JH 四个元素一致。
  4. 虚功检查：随机选小 δq 和 [F0,Tφ]，验证 τTδq 与 F0δL0+Tφδφ0 相等。
  5. 功率检查：验证 τTq̇=F0L̇0+Tφφ̇0；若只差负号，优先检查 φ0/θ 和左右镜像约定。
  6. 奇异检查：推荐实时链优先监控 ΔM、L0 和 det(JH)；ΔN 只在完整离线基准中复核。若使用条件数，先以特征腿长把 JH 两行无量纲化。接近相切时停止加长腿，不做高增益力矩测试。

6. 从目标 L0、φ0 回到电机角

先把正解和逆解分开。第 4～5 节的正运动学是一个无历史的闭式函数：只要给定当前模型角 qf、qr、固定几何参数和物理装配支路，就能直接算出 W、L0、φ0 与解析 JH；它不需要上电初态，也不需要上一周期结果。本节讨论的是反方向问题——只给目标 L0、φ0，未知 qf、qr——所以才需要迭代猜测电机角。

位置目标不再调用理想五杆的余弦定理，而是解：

H(q→)=y→d=[L0,dϕ0,d]

用上一周期测得/求得的 q 作为一个方便的初始猜测，Newton 迭代：

q→k+1=q→k+JH(q→k)−1[y→d−H(q→k)]
  • 这里的 JH 是第 5 节的解析式；Newton 每一步都重新计算当前 H 和解析 JH，不做中心差分。
  • 上一周期只用于加快逆解收敛，不参与定义机构几何。即使第一次运行，也可以使用工作域中点或一组已知可行 q 作为初猜。
  • 控制周期内目标连续，上一周期通常离新解很近，因此往往只需少量迭代。
  • 接近圆相切或 det(JH)→0 时停止加长腿，不能硬除。
  • 推荐正解只显式固定第一次闭链支路 σM=+1；完整离线基准还固定 σN=−1。逆解若存在多个 q 解，则用关节限位和“离上一周期 q 最近”选择电机解，不能把这件事误认为正解依赖历史。
  • MuJoCo 初始化还可以由 J、M、K、N、P 的朝向显式恢复四个被动角，避免先跑 3000 步 settle。
这不是三张查表。 三张“映射”只是以前为了说明正解、逆解、雅可比三个用途。优雅实现是一个统一的 H(q) 计算图：正解直接调用 H；JH 对 H 求导；逆解用 H 和 JH 做 Newton；VMC 用 JHT。

7.2 如果要自己复验，应按什么顺序

  1. 完整基准点坐标复验：随机给 10～20 组 qf、qr；完整解析正解输出 J、L、P、M、K、N、W；MuJoCo 写入同一组主动/被动 qpos 后调用 mj_forward，逐点比较。
  2. CAD 简式复验：对同一组 q 只计算 J、L、P、M，再用 P=kaL、W=P+kb(M−L)；将 W、L0、φ0、JH 与对齐后的 CAD/XML 基准逐点比较。
  3. 雅可比有限差分复验：分别只扰动 qf 和 qr，比较 H(q+δq)−H(q) 与解析 JH(q)δq；再把 δq 减半，一阶线性化余项应约缩小到四分之一。它是离线测试，不是 STM32 运行算法。
  4. 虚功/功率复验：随机给很小 δq 与虚拟力 [F0,Tφ]，检查 τᵀδq 和 F0δL0+Tφδφ0；这一步专门检出转置、φ0/θ 负号、前后列交换问题。
  5. MuJoCo 控制 A/B：在同一个模型、初始姿态、限幅和控制周期下，依次切换“旧理想 H/J”“完整两圆 H/J”“一次闭链简化 H/J”；先做零力矩、低增益静态腿长，再做小幅正弦腿长，最后才接完整 LQR。
  6. 实车模型角标定：确认每台电机的 S、Π，并用至少一个可重复参考姿态求 b；再用另外 3～5 个姿态验证同一个 b 能否复现轮轴位置。MuJoCo 通过不能替代这一步。
所以 MuJoCo 是下一步最合理的控制验证环境，但不是第一次数学验证。前 3 步先证明 H、J 和 Jᵀ 的代数链正确；第 4 步才回答“换进控制器后是否稳定”；第 5 步才回答“实车零点和几何是否与 XML 一致”。

11. 合理的下一步：只在 MuJoCo 做单变量 A/B

  1. 先修仿真诊断坐标：真实轮轴向量投影到 base Y–Z，明确与 controller body_x 的符号关系。
  2. 加入独立模式宏：SIM_OFFSET_KINEMATICS_MODE，0=完整恢复当前理想五杆，1=推荐一次闭链简式，2=完整 K–N 基准；模式 2 只用于仿真 A/B 和断言，不建议进入 MCU 实时路径。
  3. 先只换状态估计 H：控制输出仍用旧理想雅可比 Jf，比较同一 q 下 L0、φ0、θ；确认坐标和左右镜像。
  4. 再只换 JHT：关闭 MIT 位置刚度或固定为明确的低干扰配置，用小 F0、Tp 脉冲验证电机力矩方向和有限位移功率一致性。
  5. 最后换 IK：腿长从 0.15 m 缓慢扫到 0.35 m，比较实际轮轴目标、闭链 gap、ΔM、归一化后的 JH 条件指标和关节饱和；模式 2 额外记录 ΔN 作基准。
  6. 通过后再谈 LQR：保持 Q/R 不变，先确认 H/JH 修正本身的影响；不要同时重调 LQR。

通过标准

  • Hoffset 与 MuJoCo 轮轴几何：L0 < 0.1 mm、角度 < 0.1°。
  • 正逆解闭环：H(IK(y)) 在常用域内达到相同阈值，无分支跳变。
  • 虚功检查：随机小 δq 下，τᵀδq 与 [F0,Tp]δy 相对误差 < 1%。
  • 左右镜像动作：相同虚拟 F0/Tp 产生物理上对称的轮轴位移/机体作用。
  • 推荐模式出现第一次圆无交点、|ΔM| 接近零、归一化后的 JH 条件指标过大或力矩饱和，都停在仿真，不上实车；完整基准还应检查 |ΔN|。
