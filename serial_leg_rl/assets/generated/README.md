# Generated Assets

This directory is reserved for simulator-generated assets.

Examples:

- USD converted from the source URDF
- MJCF used for MuJoCo Sim2Sim
- simulator-only closed-chain constraint descriptions
- generated collision simplifications

The original URDF remains untouched. If a simulator asset needs corrected
masses, limits, or closed-chain constraints, record the change in
`docs/DECISIONS.md`.
