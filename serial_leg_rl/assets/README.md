# Assets

The source robot model is:

```text
../../wheel_leg_urdf4/urdf/wheel_leg_urdf4.urdf
```

Do not edit the source URDF in place.

When simulator-specific assets are needed, put generated USD/MJCF or patched
simulation-only artifacts in `assets/generated/`. This keeps the CAD/URDF source
separate from files that only exist to satisfy a simulator.
